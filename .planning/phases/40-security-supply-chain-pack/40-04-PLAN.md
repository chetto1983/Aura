| Boundary | Description |
|----------|-------------|
| operator shell → aura mcp console bind | The console proxies admin-token-injected requests to sidecars; binding it beyond loopback exposes that surface. |
| remote client → non-loopback console (unsafe mode) | When escalated, untrusted network clients reach the console; the per-request token is the access-control boundary. |
