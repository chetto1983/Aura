<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process → OpenRouter HTTP | The API key crosses outbound on the Authorization header; the provider's SSE response is untrusted input parsed by sse.go |
| SSE bytes → parser | Untrusted/streamed bytes; a malformed or oversized chunk must not crash or truncate |
| ctx-cancel → goroutine/HTTP | The read goroutine + HTTP body read must tear down cleanly on cancel |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | API key in HTTPError/error/log/Chunk | mitigate | Authorization set only at request-build; HTTPError.Body is provider body (never the key); dedicated anti-leak test asserts the key substring absent everywhere (release-blocking) |
| T-03-04 | Denial of Service | SSE response-size / unbounded buffer during accumulation | mitigate | bufio.Reader grows per-line but the agent's budget/step cap + max_tokens bound total volume; the accumulator keys by index (bounded by tool_calls count); document that a single line >64KB is expected but total stream is provider-bounded. No untrusted-controlled unbounded loop |
| T-03-05 | Denial of Service | goroutine/connection leak on cancel compounding across turns | mitigate | ctx rides http.NewRequestWithContext → body read returns context.Canceled ~100ms; CloseIdleConnections/DisableKeepAlives; goleak.VerifyTestMain + cancel-mid-stream test (Req#3) |
| T-03-06 | Tampering | SSE injection (`[DONE]` / `:` comment confusing the parser) | mitigate | Defensive parse: `[DONE]` is a sentinel never unmarshaled; `:` comment lines skipped before the data: check; only `data:` payloads reach json.Unmarshal |
</threat_model>
