<objective>
Implement the `aura doctor` aggregate health check (Req 10, D-09): one command that verifies the whole install with one pass/fail line per check and a non-zero exit on any hard failure. Today only the scoped `aura web doctor` / `aura mcp doctor` exist. `aura doctor` aggregates: Postgres ping, Neo4j round-trip via `mcp-neo4j-cypher`, embed dimension match (`AURA_EMBED_DIMENSIONS` vs the sidecar `/v1/embeddings`), `mcp-neo4j-cypher` spawn, and LLM-key configured-or-not. It MUST NOT use `docker compose ps` — there is no Docker socket in the box (D-09); it uses direct service probes.

Purpose: one command lets the operator (and the installer's post-install summary) confirm the stack is healthy from inside the box, without a Docker socket.

</objective>
