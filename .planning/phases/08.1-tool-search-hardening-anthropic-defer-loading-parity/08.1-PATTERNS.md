### `internal/agent/tools/search.go` (utility hook tool — MODIFY)

**Analog:** itself. The `Spec()` + `Execute()` + private `match()` triad is the contract to preserve. Only the keyword branch body changes (substring → BM25) and `Spec()` gains a dynamic Description; the `select:` branch and the `NewResult` rendering path stay byte-for-byte.

**Current Spec pattern to preserve shape of** (`search.go:26-44`) — `Spec()` returns a literal `Spec{Name:"tool_search", Deferred:false}`. The `Parameters` are a `json.RawMessage` literal. D-05 adds `max_results`; D-09 makes `Description` registry-derived (build from a *sorted* source list, no clock — see D-09 pattern below). `Deferred` stays hardcoded `false` (D-10 structural invariant: tool_search can never defer itself).

**Current args struct to EXTEND** (`search.go:22-24`):
```go

	Query string `json:"query"`
}
```
Add `MaxResults *int `json:"max_results"`` (pointer so absent → default 5, present-0 → reject per D-05; Codex `tool_search.rs:93-97` returns "limit must be greater than zero").

**Core transform to PRESERVE — the select branch + NewResult rendering** (`search.go:56-69`). This path is UNCHANGED (D-03/D-05: `select:` is uncapped, any tool):
```go
matches := ts.match(q)

	return NewResult(ctx, "no matching tools")

	s := t.Spec()
```

**Branch to PRESERVE — `select:` exact-by-name resolution** (`search.go:72-82`). Stays unchanged; resolves ANY registered tool, uncapped:

**Branch to REPLACE — the substring keyword path** (`search.go:83-95`). This is the deprecated logic (`reference_anthropic_tool_search_industrial_standard` gap at `search.go:91`). **Analog:** itself. The `Registry` methods (`Register`/`Get`/`All`, `spec.go:59-74`) are the style to match — small receiver methods on `*Registry` iterating `r.tools`.
