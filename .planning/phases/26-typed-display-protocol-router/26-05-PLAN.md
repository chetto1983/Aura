| Boundary | Description |
|----------|-------------|
| cockpit → external image host | All external thumbnails/favicons must route through the backend image-proxy, never a raw client `<img src>` |
| untrusted code body → highlighter | The highlighter must tokenize-as-text (escaped spans), never execute |
| markdown → DOM | Document markdown crosses to the DOM; rehype-sanitize is the chokepoint |
| npm registry → bundle | Two new deps cross the supply-chain boundary |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
