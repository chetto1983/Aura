<objective>
Build the "data / status" half of the display router: the typed cards that need NO image-proxy and NO citations — `table` (sort/filter/copy/CSV/paginate), `chart` (zero-dep SVG + accessible table fallback), `system_event` (web-safety + swarm-status safe-reason cards), `swarm_report` (ChildReport summary table + row expand), and `local_artifact` (filename/size/path chip). Each registers its `case` in the `DisplayRouter`.

Purpose: These five types are self-contained — they render purely from the trusted payload with no external fetch and no cross-cutting citation dependency, so they ship in parallel with the backend image-proxy/tail-inject (Wave 2). They cover DISP-04 (system_event) and SWARM-01 (swarm_report) outright.

Output: Five typed display components, wired into the router, with the locked UI-SPEC tokens, a11y, and en+it i18n. Depends on 26-02 (router shell + pagination + DisplayPayload wire type).
</objective>
