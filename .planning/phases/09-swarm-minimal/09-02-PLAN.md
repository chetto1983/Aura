<objective>
Build the ephemeral per-call swarm runner (`internal/swarm/`) — the engine that fans goals out as `LlmAgent` workers, runs them in budget-bounded leak-safe waves, isolates per-child failures (NO sibling cancellation), and collects an ordered `[]ChildReport`. This plan delivers the engine and its full unit + property test tier (SC#1/#3/#4 + D-02/D-09/D-25). It does NOT create the `swarm_spawn` tool (09-05 wires the engine to the tool) and does NOT touch any shipped file outside `internal/config/config.go`.

Architecture (RESEARCH Pattern 1, CONTEXT Discretion): BYPASS `ParallelAgent`'s escalate/first-error-cancels-siblings semantics (D-02 wants the OPPOSITE — partial results) but COPY its leak-safety idioms VERBATIM (multi-arm-select drain, `defer cancel()`, the Go #61611 spawn-loop `egCtx.Err()` guard). Each child error is captured into that child's report slot and the goroutine returns NIL — never returned to the errgroup, so no `egCtx` cancellation fires.

Purpose: the concurrency engine for CAP-03, decoupled from the tool surface so it is independently testable with `agenttest.FakeClient`. Output: `internal/swarm/{swarm,report,brief,registry}.go` + tests + 2 new config env vars.
</objective>
