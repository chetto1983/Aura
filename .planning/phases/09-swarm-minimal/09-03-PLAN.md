<objective>
The first production exercise of the `internal/agent/mcptools` seam (D-19/D-20/D-21). Three surgical edits to shipped, tested files:
1. **D-20** — flip bridged MCP tools from `Deferred:false` to `Deferred:true` (`bridge.go:88`) + update the justifying doc-comment (`bridge.go:62-68`) + add a per-server tool **allowlist** to `Mount`/`MountServer` so destructive MCP footguns (`delete_mailbox`/`move_message`/`create_mailbox`, spike-001 census) never reach a worker.

3. **D-19** — add `mail` + `whatsapp` recipes to `mcpRecipes` (`cmd/aura/mcp.go`) pointing at the spike-validated sources.

EXPLICIT D-21 non-goals (do NOT build): periodic ping ticker, restart-on-crash supervisor, lazy mount, ANY OpenClaw plugin-host machinery. The swarm engine (09-02) and the swarm_spawn tool (09-05) are out of scope here. This plan touches NO `internal/swarm/` file.

Purpose: a daily-usable (`aura chat`) mail + WhatsApp MCP surface that is footgun-filtered and dead-server-tolerant. Output: the 3 surgical edits + extended `mount_test.go` + `main_test.go` (fail-soft).
