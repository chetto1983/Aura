6. **WaitForReady function** (package-level, exported):
```go
func WaitForReady(ctx context.Context, client Client, timeout time.Duration) error {
    deadline := time.Now().Add(timeout)
    backoff := 500 * time.Millisecond
    for time.Now().Before(deadline) {
        if err := client.Health(ctx); err == nil {
            return nil
        }
        select {
        case <-ctx.Done():
            return ctx.Err()
        case <-time.After(backoff):
            backoff = min(backoff*2, 10*time.Second)
        }
    }
    return fmt.Errorf("qdrant not ready after %v at %s", timeout, client) // include baseURL in error via Stringer or field
}
```
The error message on timeout must include the Qdrant endpoint URL and total elapsed wait time per D-20.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Aura process -> Qdrant HTTP API | Qdrant is a separate process; network I/O crosses this boundary |
| caller -> NewClient | Config values (BaseURL, APIKey) come from environment; no user-controlled input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Denial of Service | WaitForReady | mitigate | Configurable timeout (120s default per D-20); exponential backoff with 10s cap; clear diagnostic message on failure preventing silent hang |
| T-01-02 | Denial of Service | httpClient.doRequest | mitigate | Response body limited to 4MB via io.LimitReader; no unbounded memory allocation from Qdrant response |
| T-01-03 | Information Disclosure | httpClient.authorize | mitigate | API key transmitted in `api-key` header only (never in URL query params); no logging of API key value |
| T-01-04 | Denial of Service | NewClient | mitigate | Empty BaseURL returns error immediately, preventing nil-pointer panics or invalid HTTP requests at runtime |
| T-01-05 | Spoofing | httpClient | accept | Qdrant endpoint URL is configured by operator via environment; MITM between Aura and Qdrant is out of scope (assumed same network/host) |
</threat_model>
