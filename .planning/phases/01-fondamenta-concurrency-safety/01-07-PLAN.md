## Reconciling ROADMAP SC#4 with locked decision D-03

**ROADMAP.md Phase 1 SC#4** reads: "A user whose message is queued behind a long-running turn receives a clear 'still processing' response within the configurable timeout period rather than hanging indefinitely."

**CONTEXT.md D-03** locks: "No per-message deadline -- queued messages wait indefinitely for their turn." (D-03 is a NON-NEGOTIABLE user decision recorded by /gsd-discuss-phase.)

These two statements are reconciled as follows: D-03 governs **wall-clock processing semantics** -- the gate does not impose a deadline that drops queued entries after some duration; the entry waits for its turn at the actor for as long as needed. SC#4 is satisfied by the **user-perceived non-hang signal** -- after `AURA_INBOX_QUEUE_NOTICE_AFTER` (default 30s), a still-processing notice is sent to the user, keeping them informed that their message is queued and will be handled. The notice does not bound processing time; it bounds **user uncertainty**. This plan implements option (a) from 01-VERIFICATION.md: queue-notice without per-message deadline.

A strict re-verifier reading SC#4 literally must read this rationale alongside D-03 before grading the criterion. The notice is the SC#4 deliverable; D-03 prevents a deadline-style misimplementation.

func (g *UserGate) Acquire(ctx context.Context, userID string, entry Entry) error {
    actor := g.getOrCreateActor(userID)

    // Per-entry started signal; closed by runActor before invoking Process.
    startedCh := make(chan struct{})
    entry.startedCh = startedCh

    for {
        select {
        case actor.inbox <- entry:
            // Successfully enqueued -- spawn the queue-notice timer (Pitfall 4: separate goroutine, never blocks the gate).
            if g.config.QueueNoticeAfter > 0 && g.config.OnQueueNotice != nil {
                go g.runQueueNoticeTimer(userID, startedCh)
            }
            return nil
        case <-ctx.Done():
            return ctx.Err()
        default:
            g.dropOldestAndNotify(actor, userID)
        }
    }
}

func (g *UserGate) runQueueNoticeTimer(userID string, startedCh <-chan struct{}) {
    timer := time.NewTimer(g.config.QueueNoticeAfter)
    defer timer.Stop()
    select {
    case <-timer.C:
        // Threshold elapsed without dequeue -> fire notice.
        g.config.OnQueueNotice(userID)
    case <-startedCh:
        // Entry began processing before threshold -> no notice.
    }
}
