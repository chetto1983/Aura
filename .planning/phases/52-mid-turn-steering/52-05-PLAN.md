<objective>
**STEER-04, the failure mode of every queue-into-a-running-thing.** Close the loss window: a steer
that was accepted while the run was live but never drained is delivered automatically as the next
user turn with a visible line, and a steer POSTed at an already-dead run is refused in a way the
operator can act on.

Purpose: this is the substantive correction the phase discussion produced (D-09). Amendment #132
originally had the operator retype the message; hermes hands the leftover back on `pending_steer` and
three independent consumers deliver it. 52-01 landed that correction; this plan implements it.

The two halves are deliberately in one plan because they are complements: the 410 covers a run that
was ALREADY terminal when the POST arrived, the auto-delivery covers a steer accepted against a live
run whose drain never came. Either alone leaves a hole, and the hole is invisible.
</objective>
