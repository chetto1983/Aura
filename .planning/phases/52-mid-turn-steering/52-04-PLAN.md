says so, replacing today's busy copy. A non-text message keeps today's behaviour.

<no_redundancy>
**Telegram is a WRAPPER over the shared seam. It re-implements nothing.** Operator directive,
binding on this plan.

The cockpit route and the Telegram branch are two callers of ONE decision path. Concretely, the
following must exist exactly once in the tree and be called, never copied:

| Concern | The one place it lives | What Telegram does |
|---|---|---|
| Emptiness / whitespace rejection | `steer.Inbox.Push` | calls it, checks the sentinel; writes NO own check |
| Byte-cap enforcement | `steer.Inbox.Push` | same; no second `len()` guard, no second cap constant |
| Queue-full / closed detection | `steer.Inbox.Push` | same; no peek-then-push race of its own |
| The conversation key | `convID(chatID)` | calls it; never re-derives a uuid, never formats one inline |
| Marker construction, the scrub, the drain | `internal/agent/llm_agent_steer.go` | touches none of it — Telegram pushes raw text and stops |
| Persistence of the steer turn | `internal/runner/runner_steer.go` | touches none of it |
| The echo payload shape | the `SteerDelta` keys from 52-02 | reuses the keys; no parallel payload |

The ONLY Telegram-specific code this plan may add is: (a) the text-vs-attachment predicate, (b) the
rendering of a `Push` sentinel into a chat reply, and (c) the `Deps` field and its injection. If a
task finds itself writing a validation rule, a cap, a key derivation or a payload shape that already
exists, that is the signal to CALL the existing one — or, if it is not callable from here, to extract
it once and have BOTH callers use it. Never a second copy.

Corollary for the sentinel→reply mapping: the HTTP route renders `Push` sentinels as status codes and
Telegram renders them as chat text. Those are two renderings of ONE classification. Keep the
classification in `internal/steer` (the typed sentinels) and let each surface render — do not let
either surface re-derive "is this too long" from the text itself.
</no_redundancy>
