<objective>
Close F-015 (SEC-07): make every Go build/test/vulnerability CI job source its package
list from scripts/go_packages.sh instead of raw root `./...`, and add a CI lint (with a
negative self-test) that rejects any future raw `./...` slipping back into a workflow.
Raw `./...` follows Go examples inside web/node_modules, so it silently exercises a
different package set than the owned-surface gates — a falsely-green assurance hole.

Purpose: One enforced rule — CI Go gates run exactly the owned package set the Makefile
runs (GO_PACKAGES := $(shell bash scripts/go_packages.sh)) — backed by a lint that
provably fails on a violation, so the rule cannot silently rot.

Output: scripts/check_ci_go_packages.sh + scripts/check_ci_go_packages_test.sh (new),
and .github/workflows/ci.yml edited at exactly 4 lines (90/117/128/181) plus shell:bash
on the two windows-unit steps plus two new lint steps in build-and-lint.
</objective>
