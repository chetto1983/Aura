<objective>
Remediate SEC-08: the critical CodeQL `go/request-forgery` (SSRF, CWE-918) where a
remote governance MCP-install request controls req.URL → managed config → OpenHTTP
cfg.URL → c.endpoint → c.client.Do(req) at internal/mcp/http_client.go:207. Transplant
the already-CodeQL-clean, mutation-tested internal/web SSRF guard into internal/mcp as a
local guard, profile-gated so loopback/private sidecars stay reachable under dev while
the cloud-metadata/scheme barrier is unconditional (the data-flow barrier that closes
the alert). DNS-rebinding is defended (hardened only) via a Dialer.Control re-check.

Purpose: Every layer protects itself (golang-security): the runtime TrustBlocked default
is a gate CodeQL cannot see, so the dial boundary must validate regardless. This closes a
real Critical and a CodeQL Critical in one transplant of known-good code.

Output: internal/mcp/ssrf.go (guard) + ssrf_test.go (table), internal/mcp/transport_ssrf.go
(enforce-only hardened client) + transport_ssrf_test.go (rebinding), and http_client.go wired
to route the endpoint through guardEndpoint with a new AURA_MCP_SSRF_ENFORCE knob (default off).
</objective>
