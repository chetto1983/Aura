## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Telegram media → sidecars | model/user-supplied audio/image/document bytes cross into the CPU sidecars (or OpenRouter for cloud vision) |
| sidecar response → conversation | the transcript/OCR/markdown is injected as a user message — its size must be bounded |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-08-SidecarDoS | DoS | voice/documents sidecar responses | mitigate | HTTP timeout 30s; documents >50MB refused; sidecar responses bounded by AURA_CONVERSATION_TURN_CAP_BYTES → sidecar spill (Task 1/2 acceptance) |
| T-13-08-AsyncLeak | DoS (resource) | documents.go 5-50MB async goroutine | mitigate | the async goroutine is WaitGroup-tracked and drained by channel Stop (goleak — Pitfall 5, Task 2) |

| T-13-08-CaptionInject | Tampering | tts.go sendVoice caption | mitigate | ASCII-sanitize the voice caption (Pitfall 4, Task 1) |
</threat_model>
