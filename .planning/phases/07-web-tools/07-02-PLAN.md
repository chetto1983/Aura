<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model/tool args → web engine | the URL host the model asks to fetch is untrusted; it crosses into DNS resolution + dial |
| DNS resolver → dialer | the attacker may control DNS answers (rebinding); the gap between resolve and dial is the TOCTOU window |
| HTTP server → client | a 3xx Location is attacker-influenced and may point at an internal target |
| web engine → model error channel | error strings cross back to the model; must not leak internal topology |
