<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model URL → fetcher | the requested URL + every redirect Location is untrusted and crosses into the SSRF gate |
| fetched bytes → readability | response bodies are untrusted; size + Content-Type must be gated before reading/parsing |
| SearXNG JSON → result mapper | the backend response must be normalized, never passed through raw (D-10) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-20 | Elevation of Privilege | fetcher.go redirect loop | mitigate | CheckRedirect disabled (Wave 2) + manual per-hop ResolveReference + validateAndPin; block at the hop with redirect_to_blocked_target, cap hops (D-29) — TestFetch_RedirectRevalidate |
| T-07-21 | Denial of Service | fetcher.go body read | mitigate | Content-Type allowlist (text/html, application/xhtml+xml) + io.LimitReader(WebResponseCapBytes) before read → unsupported_content_type / response_too_large (D-16) — TestFetch_ContentGate |
| T-07-22 | Elevation of Privilege | html.go extraction | mitigate | use readability.FromReader on already-fetched bytes; NEVER FromURL (self-fetches, bypasses SSRF) — grep-clean acceptance |
| T-07-23 | Tampering | searxng.go result mapping | mitigate | enum→raw category map, no pass-through params, no model-controlled engines/safesearch, normalized metadata only (D-10) — TestSearch_CategoryEnum |
| T-07-24 | Information Disclosure | searxng.go unavailable path | mitigate | structured web_search_unavailable{searxng_not_configured|searxng_unreachable}; no backend URL/body leaked (D-06/D-27) — TestSearch_Unavailable |
| T-07-25 | Denial of Service | fetcher.go retry | mitigate | at most one retry within deadline on transient/408/429/5xx; no retry on SSRF/4xx/config (D-23/D-42) — TestRetry_Policy |
</threat_model>
