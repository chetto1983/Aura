## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator config → app | `SEARXNG_URL` and `AURA_WEB_*` env values are operator-controlled (trusted); a missing/empty value must fail closed (no autodetect, no public fallback) |
| SearXNG container → public internet | SearXNG egresses to the internet on the shared network; it has NO host port so it is not reachable from outside the Compose network |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Information Disclosure | searxng Compose service | mitigate | NO `ports:` key — internal-network-only; not bound to any host interface (D-03); verified by `docker compose config` grep |
| T-07-02 | Tampering | searxng/settings.yml | mitigate | mounted `:ro` (read-only) so a compromised container cannot rewrite its own config (D-04) |
| T-07-03 | Denial of Service | config load on missing SEARXNG_URL | mitigate | fail-CLOSED as a structured `searxng_not_configured` at call time, NOT a boot-fatal — `aura db migrate` and other subcommands keep working (D-05/D-06) |
| T-07-SC | Tampering | go get of the two new modules | mitigate | Package Legitimacy Gate checkpoint (Task 1) verifies exact module paths on pkg.go.dev/codeberg before install; [SLOP] verdict is a documented false positive |
