<objective>
Close the env-load class (M-i — root cause of a whole class of operator-subcommand `.env`-invisibility)
plus the independent residual LOWs and document the INFO finding. M-i: `aura mcp <sub>` reads
`AURA_MCP_CONFIG` via `ManagedConfigPath` but `godotenv.Load()` lives only in `config.Load*`/`llm.Load`,
which the `aura mcp` dispatch path (except `mcp tools`) never calls — so `.env`'s `AURA_MCP_CONFIG` is
invisible and the operator edits the DEFAULT `~/.aura/mcp/servers.json` while `aura serve` reads the
intended file. ONE central `_ = godotenv.Load()` at `main()` start closes the whole class (D-01b — it
also fixes the `aura mcp doctor` whatsapp-URL and `agent dry-run`/`swarm-demo`
`AURA_LOOP_*`/`AURA_SWARM_MAX_DEPTH` free-rider LOWs). godotenv is load-first-wins (won't override set
vars), so the central call is idempotent with the existing per-command loads.

Independent LOWs (no coupling, one file each): L1 (host snippet exec has no timeout/cancellation —
`context.Background()`, a runaway snippet hangs forever on the operator CLI while `shell_exec` enforces
120s), L2 (`Writer.Activate`/`Writer.DiscardPending` skip the `SanitizeName` chokepoint before
`os.RemoveAll` — not exploitable today since live callers pre-validate, but the sibling methods all
guard), L4 (`SearchConversationTurns` has no status filter so soft-deleted conversations' turns stay
searchable — latent, no command sets StatusDeleted today), L6 (web_search/web_fetch don't reject an
empty required `query`/`url` → SearXNG returns "no results" instead of "query required").

INFO (D-01a): the self-installed-skill-bundled-scripts-not-scanned finding is DELIBERATE per the
full-host-terminal trust model (amendment #50 / D-15c) — document the trust boundary explicitly, do NOT
add a scanner.

Purpose: kill the operator `.env` gap + the small safety/UX gaps + record the trust boundary.

Output: the central godotenv.Load(), the snippet timeout, the two SanitizeName guards, the status guard,
the empty-arg rejections, and the INFO trust-boundary doc.
</objective>
