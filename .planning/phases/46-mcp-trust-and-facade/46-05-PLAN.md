<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Sidecar HTTP port -> anything on the docker network | The sidecar serves whatever it registers; Aura's namespacing protects the model's surface, not this port. |
| Fork repo -> Aura repo | Only the published image crosses; no Aura CI job can inspect the fork's contents. |
| Model-supplied `action` -> provider call | The action string selects which real provider side effect runs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-15 | Elevation of Privilege | Unadvertised-but-callable raw handlers | mitigate | D-26: the 14 classes are DELETED, not unregistered; acceptance greps the source tree for their absence. An unadvertised handler is reachable by anything holding the port. |
| T-46-16 | Spoofing | The opaque account/event reference (MCP-05) | mitigate | The detail action requires the reference the fork itself issued and no `accountId`; no default account can be substituted, which is the exact failure host-side injection would have caused. `accountId` survives only where it is genuinely a defaultable routing hint, and the descriptions say which is which. |
| T-46-17 | Tampering | Supply chain — which surface is actually live | mitigate | D-23: the artifact is the immutable `:<sha>` tag published by the fork's own workflow, verified by pulling that exact tag and issuing a real `tools/list` before anyone pins it. A floating `:sidecar` tag would make "which surface is live" unanswerable from the tree. |
| T-46-18 | Elevation of Privilege | An unrecognised `action` reaching a default branch | mitigate | Unknown action returns a tool error naming the valid actions; there is no default action and no fall-through. Aura's side saturates the same input upward to Risky (plan 46-06). |
| T-46-19 | Denial of Service (context budget) | The always-loaded merged description | mitigate | Measured < 2048 bytes against a 4,096-byte host cap, with per-field detail pushed into 512-byte argument descriptions. |
| T-46-SC | Tampering | package installs | mitigate | No new package is added in either ecosystem; this is a curation diff inside an existing project. Nothing to gate. |
</threat_model>
