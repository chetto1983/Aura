<assumption_delta_decision>
**Noun now primary:** *a curated multiplexed tool per mounted server* — NOT *the comms surface*.

**Decision: `promote`.** MCP-04 was written around one singular `comms` surface. That noun cannot
exist: a single MCP tool cannot be served by two servers without merging the two forks (D-17/D-18),
and D-27's always-loaded rule is already expressed per-server (a server earns a slot by its own tool
count). The per-server curated tool is therefore the real unit, and the amendment written by this
plan states it in the plural.

**Consequence carried into code (plans 46-04/06/08):** the invariant test asserts *every* name
returned by `mcptools.MultiplexedMCPTools()` has exactly one `multiplexedClassifiers` entry, for
every mounted server — so a future phase reintroducing the singular assumption goes red rather than
silently under-gating a second server.
</assumption_delta_decision>
