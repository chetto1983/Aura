|----------|-------------|
| LLM pause Event → Runner | the Runner is the sole writer of paused_states; a stray writer would corrupt FIFO state |
| resume answer → loop history | injected RoleTool must match the original tool_call_id (wire-correctness) |
| CLI purge/delete → Postgres + filesystem | destructive ops must be --confirm-gated |
| boot scan → filesystem | symlink escape (mitigated in 04-04 ScanOrphans, invoked here) |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-19 | Tampering | multiple writers to paused_states corrupting FIFO/resume state | mitigate | the Runner is the SOLE writer (D-A1-08); Stores expose Insert but only the Runner calls it on a pause Event (Task 1) |
