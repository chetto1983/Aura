<objective>
Build the rerank foundation: a fail-soft GPU reranker sidecar and a Go client that
mirrors `documents.EmbeddingClient`. This is the substrate RET-02/RET-04 wire into.

Purpose: Spike 070 proved a cross-encoder reranker measurably beats pure vector
retrieval (kills TOC/lexical false positives), but only on GPU (CPU = 23s, dead).
The reranker must be a drop-in, optional sidecar: when GPU/sidecar is absent,
retrieval degrades to the existing RRF/vector order and NEVER hard-fails.

Output: `aura-rerank` compose service (Qwen3-Reranker-0.6B Q4_K_M on `server-cuda`),
`internal/rerank` package with `RerankClient`/`Scored`/`Rerank`, `AURA_RERANK_BASE_URL`
config wiring, unit tests, and a live `rerank_integration` tier.
</objective>
