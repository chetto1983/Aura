<objective>
Harden and widen the full-document ingest pipeline so ANY markitdown-supported format
ingests E2E, and add the connected-graph (:NEXT_CHUNK) reading-order edges that RET-04
expands over.

Purpose: Today isSupportedDocument artificially caps ingest to 4 formats (pdf/xlsx/xlsm/docx)
and the indexer only writes :HAS_CHUNK. The operator directive (2026-06-20) is full-docs across
ALL markitdown formats with format-aware locators, plus the connected (:Chunk)-[:NEXT_CHUNK]->(:Chunk)
graph the spike-070 pipeline requires. No DB migration — Neo4j stays, 384d Granite embeddings stay.

Output: a single extension allowlist, widened markitdown /extract handlers (PPTX/HTML/CSV +
generic fallback), :NEXT_CHUNK edges in the indexer, updated docs, and a live tier proving
the G220 PDF plus a non-PDF format.
</objective>
