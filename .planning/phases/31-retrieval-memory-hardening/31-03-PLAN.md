<objective>
Wire two-stage retrieval — vector/BM25 seed → rerank seeds → graph-expand winners — into
BOTH document retrieval (Go) and memory recall (agent-memory sidecar), with RRF fallback and
the messages[0] KV-cache invariant preserved.

Purpose: This is the value of the phase. Spike 070 Q4 proved the FAST order is rerank-the-seeds
(267ms) not expand-then-rerank (1.4s). The reranker fixes TOC/lexical false positives on the
noisiest surfaces. Both surfaces degrade to RRF/embedding order when the reranker is absent.

Output: a documents.Service.Retrieve two-stage path consumed by the document_search tool, and a
fail-soft rerank post-processor in the agent-memory sidecar's recall path.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent loop → documents.Retrieve | user query crosses into the seed/rerank/expand pipeline |
| agent-memory sidecar → aura-rerank | recall result text crosses to the reranker |
| retrieval results → LLM context (messages) | reranked chunks are appended to the prompt (must not disturb the cached prefix) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-07 | Tampering | retrieval wiring mutating the cached messages[0] prefix | mitigate | Retrieve is a pure chunk function; results are appended downstream, never injected into messages[0] (cache-invariant gate in RET-05) |
| T-31-08 | Denial of Service | rerank latency stalling the agent loop | mitigate | rerank only the ~10 seeds with short truncation (267ms fast-path); fail-soft timeout → seed order |
| T-31-09 | Information Disclosure | recall rerank leaking memory text to logs | mitigate | Python rerank logs only a reason, truncates wire text, never logs full content |
| T-31-10 | Elevation of Privilege | scope bypass via reranked memory crossing user boundary | accept | rerank only REORDERS already-scoped SEARCH_*_BY_EMBEDDING_SCOPED results; it adds no rows and cannot widen scope |
</threat_model>
