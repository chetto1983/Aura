<objective>
Register `agent-memory` as a trusted, default-on, fail-soft managed MCP recipe so the agent
gets the full 16-tool memory surface (Deferred + `memory__*`) out of the box, with no
explicit `aura mcp install` and no DenyRisk filter. This plan satisfies D-05 (conversational/
agent memory via the package's native MCP surface), D-06 (full 16-tool surface), D-07
(Deferred + namespaced), D-08 (default-on trusted recipe — THE genuine new design node),
D-09 (fail-soft + reconnect, no supervisor), D-10 (single-user `local` scope), D-11 (384d
loopback URL), and re-scoped UX-09 (agent-written reasoning/insight recalled on demand —
the reasoning-trace tools are in the 16).

Purpose: A catalog entry alone mounts NOTHING (Pitfall 1 — every existing recipe is opt-in
`aura mcp install`, and `LoadManagedConfig` returns empty on a fresh machine). Memory is a
core capability → on out of the box. The ONLY new behavior in the phase is the default-on
seam; the mount/bridge/fail-soft chain is REUSE-as-is (proven by spikes 032/035). This plan
delivers the recipe + the default-on seam and asserts the surface with unit tests; the live
16-tool assertion lands in 15-04's `memory_integration` tier.

Output: a `memory` `CatalogEntry`, an inject-unless-disabled default-on seam in
`loadMCPServers`, and unit tests for the recipe golden + default-on + disable-respect.
</objective>

| Go process → loopback sidecar (`127.0.0.1:8091`) | The streamable-HTTP MCP transport; loopback-only, no auth surface (single-user `local`). |
| default-on injection → agent tool surface | Registering memory default-on widens the agent's reachable tool set to 16 memory tools without an explicit operator install. |
