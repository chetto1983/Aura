| Boundary | Description |
|----------|-------------|
| local operator CLI → MCP config + audit ledger | A CLI mutation must be attributable (cli:<user>) and leave an append-only audit trail, or be disallowed under production. |
| CLI caller ↔ shared TrustApprove | A validation guard that lives only in the web handler must not be bypassable by the CLI reaching TrustApprove directly. |
| web trust HTTP body → config/audit | Underspecified trust bodies must 400 with no mutation (already shipped; guard against regression). |

| T-38-12 | Validation (V13/V5) | TrustApprove dead-fallback back door (F-038 via CLI, Pitfall #5) | mitigate | Remove the empty-class default; centralize validation in TrustApprove; keep the web 400 gate; verified by TestGovernanceWriteTrustRejectsUnderspecified + a CLI no-reason rejection. |
