<objective>
Fix the two raw-transport lifecycle bugs in the stdio MCP client: (D-08/D-09) replace the unbounded
`bufio.Reader.ReadBytes('\n')` frame read with a bounded `bufio.Scanner`+`.Buffer(_, AURA_MCP_STDIO_MAX_FRAME)`
that aborts the whole transport deterministically on an over-cap frame (never resync), and (D-10) replace
`killProcess`'s single-PID `cmd.Process.Kill()` with a process-tree kill by extracting the already-proven,
CI-shipped per-OS process-group-kill pair from `internal/agent/tools` into a shared `internal/procgroup`
package that both packages import.

Purpose: MCPH-05 (a hostile/misbehaving stdio server can no longer OOM the host with an unterminated line)
and MCPH-06's kill half (no leaked grandchild processes on Close). Both are Denial-of-Service mitigations
(ASVS V7 error-visibility + resource-exhaustion). This plan deliberately does NOT change `mcp.Open`'s ctx
signature — the mount-timeout two-context split (D-06) is 38-05, which builds on the `setProcessGroup(cmd)`
wiring this plan installs.
Output: `internal/procgroup` (new shared package) + a bounded, tree-killing `client.go`.
</objective>
