<objective>
Add the D-14/D-15 legacy-env production gate: under `server_production`, if `AURA_MCP_SERVERS_JSON` is set
but `AURA_MCP_LEGACY_ENV_COMPAT=1` is NOT, boot hard-errors with a message naming both env vars. Under
`dev`/`local_trusted` the legacy env keeps parsing byte-identically. This mirrors the already-shipped

boot wiring is needed beyond registering the gate.

legacy MCP server set left over from a dev config. This is a textbook ASVS V14 "secure-by-default, explicit
opt-out" configuration control. Fully independent of the classifier/lifecycle work → Wave 1, no dependencies.
Output: `gateMCPLegacyEnv` + its table test + the compat-flag knob registration.
