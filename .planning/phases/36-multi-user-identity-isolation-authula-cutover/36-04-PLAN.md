<objective>
Build the Postgres kernel backstop (D-07) and the owner-scoped conversation/approval surfaces that make
MUSR-01/02 observable. `db.WithIdentityTx` sets `app.current_identity` transaction-locally; the RLS
policies on `conversations`/`conversation_turns`/`paused_states` compare it to `identity_id`. The
`*ForIdentity` sqlc queries + handlers are the primary correctness path (the observable 404/403, D-06);
RLS is the backstop that returns 0 foreign rows even for a query that forgot the filter.

The RLS ENABLE migration ships HERE (0032), co-located with the `WithIdentityTx` read-path that makes it
safe — enabling RLS while owner-scoped reads still run on the pooled `s.q` would fail-closed to 0 rows
(RESEARCH Pitfall 1). This plan moves every owner-scoped conversation/approval read into `WithIdentityTx`.

Purpose: MUSR-01 cross-deny (conversations + approvals) + MUSR-02 (new conversation owned by principal) +
the RLS backstop. Assets already ship `*ForIdentity` (internal/assets) — reuse that convention verbatim.
Output: `WithIdentityTx`, RLS migration 0032, `*ForIdentity` queries/stores/handlers, 404/403 mapping,
MUSR-02 owner, RLS backstop test.
</objective>
