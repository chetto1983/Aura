Land the rollout and the MUSR-01 acceptance gate: backfill the Neo4j `:User{local}-[:HAS_DOCUMENT]` edges to
ALL existing documents BEFORE the fail-closed flip (D-12 — else the operator's docs vanish), enforce the
deploy→backfill→verify→flip ordering (D-13), add Garage(admin)+Authula to the CI live stack (D-29), and ship
the two-identity cross-deny live E2E that gates on Linux CI under no-skip-as-green.

The rollout leans on plan 05's flag-gated dual path (D-13): while `AURA_MUSR_ISOLATION=off` the documents
retrieval runs the PRE-EXISTING UNSCOPED query (no enforcement, operator sees all) — so the deploy step is
safe even before the backfill; the flip to `on` is the enforcement switch that activates the scoped
fail-closed path, made safe by the backfill having attached an owner edge to every doc first.

This is the phase's hard-ordering keystone: it depends on the scoping code (04/05), the Garage client (06),
the sagas (08), the delete lifecycle (09), the frontend (10), and Telegram/token gate (11). The E2E provisions
A + B, has A upload a doc + write a conversation + start a bg job, then asserts B gets 404/403 on every A
resource and an empty `document_search`, plus the MUSR-02/06 happy path (B-created chat owned by B and runs;
provision→login→isolated-run; break-glass works).

Output: idempotent backfill, rollout runbook, CI stack + tags, the two-identity cross-deny gate.
