<objective>
Build the minimum GAP-2 web-auth boundary (WEB-03) as a new, stdlib-only
`internal/agui/auth.go` (+ `auth_cookie.go`): a `POST /login` that constant-time
compares `AURA_WEB_AUTH_SECRET` and mints an HMAC-SHA256-signed, HttpOnly+Secure+
SameSite=Strict session cookie bound to the seeded `local` identity (D-01/D-02);
a `RequireAuth` middleware that gates the whole origin EXCEPT the login page +
assets + `/healthz` (D-03); a `POST /logout` that clears the cookie; and a
`capability_grants` check on the only mutating route `POST /agent/run` (D-04). Wire
it into `newServeHandler` (wrap the parent mux) and thread the auth deps from
`bootServe`. The middleware is a pass-through no-op when no secret is configured
(loopback dev), which the Plan-01 boot guard guarantees only happens on loopback.

Purpose: this is the milestone's auth trust boundary — it activates the dormant
`capability_grants` scaffolding and makes the cockpit usable AND protected on a
network at the end of Phase 24.
Output: `auth.go` + `auth_cookie.go`, the mux wrap, the bootServe wiring, and the
full security test suite (unit + property + db_integration).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `POST /login` | An untrusted client submits the operator passphrase; the secret compare and cookie issuance happen server-side. |
| browser cookie → every protected request | The signed session cookie is the only client-presented credential; it crosses on each request and is HMAC-verified server-side. |
| reverse proxy → daemon (trust-proxy path) | When `AURA_WEB_TRUST_PROXY=true`, the proxy terminates auth; Aura must not trust any proxy-injected identity header. |
| principal → `capability_grants` | The bound identity authorizes the mutating `POST /agent/run` against DB-backed grants. |

| T-24-10 | Tampering | session forgery via a forged/edited cookie | mitigate | HMAC-SHA256 signature verified with `hmac.Equal` (constant-time); single-byte-tamper rejection is a property test (Task 1). |
