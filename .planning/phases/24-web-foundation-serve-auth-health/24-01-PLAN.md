Add the WEB-02 fail-fast non-loopback boot guard. Introduce two config knobs
(`AURA_WEB_AUTH_SECRET`, `AURA_WEB_TRUST_PROXY`) following the existing AG-UI env
block, lift the historical hardcoded-loopback restriction on `AURA_AGUI_BIND`
(D-06), and add a pure-function `config.GuardWebBind` that refuses a non-loopback

actionable message instead of silently exposing an unauthenticated surface.

Purpose: this is the foundational policy gate the rest of the phase relies on —
the in-binary cookie auth (Plan 03) is only mandatory because this guard refuses
exposure without it; on loopback (where Plans 02/03 run unauthenticated by design)
the guard is a no-op so dev boot is unchanged.
Output: `WebAuthSecret`/`WebTrustProxy` fields, `GuardWebBind`, the `bootServe`
guard call, the boot-guard test matrix, and the documented `.env.example` knobs.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network → `aura serve` listener | The `AURA_AGUI_BIND` address decides whether the daemon is reachable beyond loopback; a non-loopback bind crosses an untrusted-network boundary. |
| operator env → daemon boot | `AURA_WEB_AUTH_SECRET` / `AURA_WEB_TRUST_PROXY` are operator-supplied boot inputs that gate exposure. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-01 | Information Disclosure / Elevation of Privilege | non-loopback bind with no auth | mitigate | `GuardWebBind` fail-fast: a non-loopback `AURA_AGUI_BIND` with neither credential returns a boot error → `os.Exit(exitInfra)` (Task 1+2). |
| T-24-02 | Spoofing | wildcard bind `0.0.0.0`/`::` treated as safe | mitigate | `net.ParseIP(...).IsLoopback()` returns false for wildcards → gated; covered by the test matrix (Task 2). |
| T-24-03 | Tampering | a bare-host `AURA_AGUI_BIND` (no port) bypassing the parse | mitigate | `net.SplitHostPort` error falls back to `host = bind` so the loopback check still runs (Task 1). |
| T-24-04 | Denial of Service | guard panics on malformed bind, crashing boot | accept | `GuardWebBind` is total (no panic path: SplitHostPort error is handled, ParseIP nil is handled) — a malformed non-loopback string fails CLOSED to the gated branch, which is the safe outcome. |
| T-24-SC | Tampering | npm/pip/cargo installs | mitigate | This plan introduces ZERO new packages (stdlib `net`/`strings`/`fmt` only); no install task, no slopcheck surface. |
</threat_model>
