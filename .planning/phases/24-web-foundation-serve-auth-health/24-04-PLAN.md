## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → served SPA | The embedded login page + health panel run untrusted JS in the operator's browser; the cookie is HttpOnly so JS cannot read it. |
| SPA → same-origin REST (/healthz, /readyz, /login) | The health poll + login submit are same-origin fetches; SameSite=Strict + the server-side gate (Plan 03) govern them. |
| real binary boot | The serve_smoke test exercises the actual `aura serve` exposure decision and auth redirect end-to-end. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-20 | Information Disclosure | the health panel leaking secrets/raw DSNs | mitigate | The panel reads only `/healthz`+`/readyz` whose bodies are already `SanitizeString`-redacted (agui server); no raw secret is rendered; bind/build are non-secret. |
| T-24-21 | Spoofing | a client-side route guard mistaken for the real auth boundary | mitigate | The router provides navigation + a client 404 only; the server's RequireAuth (Plan 03) is the enforced boundary — documented in Task 1; no route is "protected" purely client-side. |
| T-24-22 | Tampering | a stale committed `dist` shipping an old (unauthenticated) shell | mitigate | The Phase-23 dist-freshness gate + the rebuild-and-commit step (Task 3) ensure the embedded assets match the source. |
| T-24-23 | Information Disclosure | XSS stealing the session cookie | mitigate | `HttpOnly` (Plan 03) blocks JS cookie read; the SPA adds no `dangerouslySetInnerHTML` on untrusted data; CSP from the Phase-23 PWA. |
| T-24-24 | Elevation of Privilege | serve_smoke false-green by skipping under CI | mitigate | the `$CI` no-skip-as-green `t.Fatal` discipline is mirrored in the smoke test (Task 4). |
| T-24-SC | Tampering | npm installs (`react-router-dom`, `@tanstack/react-query`) | mitigate | Both are mature, ubiquitous packages added INSIDE the Phase-23-locked toolchain (not new Go backend deps); the web supply-chain gate from Phase 23 governs the lockfile. No Go package-legitimacy gate applies (zero Go packages added this phase). |
