<objective>
Move Aura's agent bridge onto `*sdkmcp.ClientSession` and delete the hand-rolled reconnect and
liveness-poll layers, replacing them with the SDK's own push signals plus the one thing no MCP
library can decide for a host: redial policy.

Purpose: this is the seam the whole phase exists to move. It is also where the phase's single
easiest silent regression lives — the `decodeToolResult` → `decodeToolCallError` chain whose only
call site is inside a file being deleted.
Output: `MountedServer`, the re-plumbed result-decode chain, the `_meta` sending middleware, and
594 fewer LOC of bespoke reconnect/poll code.
</objective>
