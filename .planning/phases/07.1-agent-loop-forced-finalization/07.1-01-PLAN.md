<objective>
Thread a provider-neutral `ToolChoice` directive end to end (Req#1): add a `ToolChoice string` field to `llm.Request`, and change `openai_compat.buildWireRequest` so it sends `req.ToolChoice` (defaulting to `"auto"` when empty, byte-identical to today) and omits the `tools` array entirely when `ToolChoice=="none"`. This is the FOUNDATION (RESEARCH §2) that unblocks `finalize()` (plan 02) sending a tool-free `"none"` synthesis turn.

Purpose: Without this field there is no way to force a tool-free synthesis turn; `client.go:141` hardcodes `"auto"` today. Implements SPEC Req#1, INFRA-03 (extends the Slice 0.9 budget/loop contract — same provider-neutral request model).
Output: One new optional field, one wire-serialization branch, and the regression-guard + new-case tests.
</objective>
