<objective>
Inject a `<budget>used=N remaining=M</budget>` block as a TRAILING `user`-role message via the single assembly chokepoint `PromptBuilder.Build` (Req#6, P2 fan-out control). The block reports used/remaining tool steps so the model curbs over-fetching (the `web_fetch`×5 repro). It is appended to a COPY of the history slice so `messages[0]` stays byte-identical every turn (KV-cache poisoning guard, D-04/D-05).

Purpose: The prompt carries no budget signal today; the model over-fetches. This is fully independent of the finalize spine (RESEARCH §2) — its only shared surface is the read-only `Budget` accounting. Implements SPEC Req#6, INFRA-03 (the `<budget>` block is a new clause on the same `Budget` accounting — `Remaining`/`branchConsumed`).
Output: An extended `Build` signature, the tail-injection branch, and the byte-stability + tracking test.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Budget accounting → prompt | The builder reads (never writes) `branchConsumed`/`Remaining()` and emits a directional `<budget>` string into the model-visible prompt. No external/network/auth surface. |
| cached prefix `messages[0]` | The `<budget>` block changes every turn; placing it in the stable prefix would poison the KV cache. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-07.1-02 | Tampering | `messages[0]` cache-prefix integrity | mitigate | The `<budget>` block tail-injects to a COPY of history as a trailing `user` message (D-05); `a.history` and `messages[0]` are never mutated. Guarded by the new `TestBudgetBlock` byte-stability assertion + the existing `TestPrompt_ByteStable` (landmines #1/#2). Integrity guard, not a security boundary. |
| T-07.1-03 | Information Disclosure | `<budget>` block content | accept | The block emits only two integers (`used`/`remaining`) — no secrets, no PII, no raw provider errors. No leak surface. |

No high-severity threats: a two-integer directional hint in the prompt tail with strict cache-prefix isolation.
