## Pattern Assignments

### `internal/agent/llm_agent_finalize.go` (NEW — agent loop logic, streaming)

**Analogs:** `internal/agent/llm_agent.go` (the `consume` drain + content-stop `finalEvent` path) and `internal/agent/llm_agent_events.go` (`finalEvent` / `terminalBudgetEvent`).

This is the spine file. It contains `finalize()`, the retry, the deterministic Italian stub, and (per D-08) the recovery-counter logic invoked from the trip sites. It lives in a NEW file because `llm_agent.go` is 329 LOC (D-07, no-god-class headroom).

**Pattern A — the EXACT `finalEvent` constructor signature to emit through** (`llm_agent_events.go:62-70`):

```go
func (a *LlmAgent) finalEvent(ic InvocationContext, spanID [8]byte, parentSpanID *[8]byte,
	requestID, answer, finish string, usage llm.Usage,
) *Event {
	_ = requestID
	ev := a.newEvent(ic, spanID, parentSpanID)
	ev.LLMResponse = &LLMResponse{Content: answer, FinishReason: finish}
	ev.Actions.StateDelta = usageStateDelta(usage)
	return ev
}
```

**How a non-empty-`Content` Event is built and yielded** (content-stop path, `llm_agent.go:160-169`) — this is the EXACT shape `finalize()` must reproduce: build a `finalEvent` whose `LLMResponse.Content` is non-empty, append the answer to history, then yield:

```go
if len(calls) == 0 {
	answer := text
	if finish == "length" {
		answer += truncationNotice
	}
	a.history = append(a.history, llm.Message{Role: llm.RoleAssistant, Content: answer})
	yield(a.finalEvent(ic, spanID, parentSpanID, requestID, answer, finish, usage), nil)
	return
}
```

> **Pattern to replicate:** `finalize()` builds the tool-free request, drains the stream to a `content` string (NOT `tool_calls` — landmine #4), then emits **exactly one** `finalEvent(...)` with non-empty `Content`. The terminal user-facing Event is ALWAYS a `finalEvent`, never the `iter.Seq2` error slot (landmine #10, L2).

**Pattern B — preserve observability (landmine #10).** `finalEvent` does NOT stamp a `termination_reason` today (only `terminalBudgetEvent` does, see below). Req#2 requires finalize to preserve the reason. Copy the `StateDelta` map shape from `terminalBudgetEvent` (`llm_agent_events.go:91-101`) and merge it onto the finalEvent's StateDelta inside `finalize()` (or build a dedicated event):

```go
func (a *LlmAgent) terminalBudgetEvent(ic InvocationContext, spanID [8]byte, parentSpanID *[8]byte, reason string) *Event {
	ev := a.newEvent(ic, spanID, parentSpanID)
	ev.Actions = Actions{
		Escalate: true,
		StateDelta: map[string]any{
			"termination_reason": "budget_exhausted",
			"limit_hit":          reason,
		},
	}
	return ev
}
```

> The finalized Event must carry BOTH the usage delta (`usageStateDelta`) AND the `termination_reason`/`limit_hit` keys. Do not just call `finalEvent` and return — augment its `Actions.StateDelta` map. `terminalBudgetEvent` is being **replaced** as the terminal Event but its StateDelta keys are PRESERVED inside the new finalEvent for observability.

**Pattern C — stream-drain + the after-false contract (L2, landmine #12).** `finalize()` calls `a.client.Stream(...)` and drains the channel. Mirror `consume` (`llm_agent.go:269-298`): a tool-free turn only needs the `c.Text` / `c.FinishReason` / `c.Usage` cases, but if it yields chunk Events through the same `yield`, it MUST honor the after-false guard and drain-to-close:

```go
case c.Text != "":
	b.WriteString(c.Text)
	if !yield(a.chunkEvent(ic, spanID, parentSpanID, c.Text), nil) {
		for range ch { //nolint:revive // drain-to-close
		}
		return b.String(), calls, finish, usage, true
	}
```

> Simplest safe approach for the tool-free turn: drain the channel fully into a `strings.Builder` WITHOUT yielding intermediate chunks (just accumulate `c.Text`, capture `c.Usage`), then emit one terminal `finalEvent`. This sidesteps the after-false hazard entirely for the synthesis turn while still being goleak-clean (FakeClient pre-closes; the real client needs the full range to close). If chunks ARE streamed, the after-false guard above is mandatory.

**Pattern D — retry-once + deterministic Italian stub (Req#5 / D-09).** No analog for the retry loop itself (it is new), but the stub iterates `a.history` filtering `Role == llm.RoleTool` — the RoleTool messages are appended at `llm_agent.go:230-232`:

```go
a.history = append(a.history, llm.Message{
	Role: llm.RoleTool, ToolCallID: call.ID, Content: preview,
})
```

> Stub pattern: on empty/error → retry `finalize()` once → still empty/error → build the D-09 Italian stub. Lead-in literal (load-bearing, a test asserts the prefix): `Non sono riuscito a completare la sintesi finale, ma ecco i dati che ho raccolto:` then one `- {tool}: {preview}` bullet per `RoleTool` entry in `a.history` (per-bullet ~500B cap + overall cap — exact caps are Claude's-discretion per D-09). `llm.RoleTool == "tool"` (`client.go:18`). Emit the stub as the `finalEvent` `Content` — never empty prose (no code path may yield empty).

**Pattern E — recovery counter (D-08, landmine #3).** New `recoveryAttempts int` field on `LlmAgent` (see `llm_agent.go` below). The gate is a COUNTER, never a one-shot boolean latch (CrewAI #1656). First trip → increment + inject nudge + one more turn; any subsequent trip → `finalize()` immediately.

**Nudge wording (D-02 / D-03, English, no IT directive — `SystemPrompt` governs language):**
- Recovery (`user` role, once): `"You have already called {tool} with these arguments and the result will not change. Do not repeat any tool call — answer the user's question now using the results you have already gathered."`
- Finalize synthesis (`user` role, with `ToolChoice="none"`): `"Stop calling tools. Using only the tool results already gathered above, write the final answer to the user's original question now."`
- **landmine #9:** the pure-budget (max_steps/wallclock) trip at `:124` has NO offending `{tool}`. Use a generic nudge variant that omits the `{tool}` clause on that path; only the dedup trip (`:224`) has `call.Function.Name` in scope.

> **Pattern to replicate:**
> - **Budget-bypass for recovery (landmine #5, Req#4):** the recovery turn must re-enter the loop WITHOUT passing through the `:124` `ConsumeStep` gate again (with the counter at 0 there is no budget left — gating it makes recovery impossible). Ceiling: `max_steps + 2` total LLM calls.
> - **Event-only, never the error slot (L2, D-04):** the trip emits an Event (now a `finalEvent` via the new file), never `yield(nil, err)`. Only a real Stream transport failure uses the error slot — and the guaranteed-answer contract means the terminal Event is always a non-empty `finalEvent`.

> - **Recovery nudge IS appended to `a.history`** (it is real conversation state, exactly like the assistant tool-call messages at `:176`/`:180`/`:217`). Contrast with the `<budget>` block which is NEVER appended to `a.history` (landmine #1).

## Shared Patterns

### L1 — Byte-stable `messages[0]` / KV-cache discipline
**Source:** `internal/agent/prompt.go` (`SystemPrompt`, immutable prefix) + `prompt/builder.go:29` (`Messages: history` as-is) + `prompt_test.go:TestPrompt_ByteStable`.
**Apply to:** `prompt/builder.go` (the `<budget>` block MUST tail-inject to a COPY), `llm_agent.go` (recovery nudge appends to `a.history` tail, never the prefix).
> Every assembly path keeps `messages[0]` byte-identical across turns. The `<budget>` block (changes every turn) is the live test of this — trailing `user` message only. Cache-poisoning sites are mapped (memory `reference_aura_cache_poisoning_sites`). This OVERRIDES any convenience that would touch the prefix.

### L2 — `iter.Seq2` after-false drain contract
**Source:** `internal/agent/llm_agent.go:152-158` (the `stopped` check after `consume`) + `:282-289` (drain-to-close).
**Apply to:** `llm_agent_finalize.go` (the finalize stream drain) and every trip-site re-route.
```go
if stopped {
	return // consume returned false from a yield; any further yield panics
}
// ... and inside the consumer:
if !yield(ev, nil) {
	for range ch { /* drain-to-close — no goroutine leak */ }
	return ..., true
}
```
> Budget/dedup trips and finalize emit Events through `yield`; a `false` return means STOP (never yield again). Real infra failures use `yield(nil, err)` (D-15) — but the guaranteed-answer contract means the terminal user-facing Event is ALWAYS a non-empty `finalEvent`, never the error slot.

### Optional-field wire serialization (backward-compat)
**Source:** `openai_compat/client.go:54-64` (`omitempty` wire fields) + `buildWireRequest:136-148`.
**Apply to:** `client.go` (`ToolChoice` field) + `openai_compat/client.go` (default-when-empty).
> Default `ToolChoice` to `"auto"` when empty so every existing caller serializes byte-identically (Req#1 acceptance; the existing `TestRequestBody` is the regression guard). `"none"` additionally nils `Tools` so `omitempty` drops the key.

### Error wrapping + sentinels
**Source:** `llm_agent.go:307` (`fmt.Errorf("parse error: %w", err)`), CLAUDE.md golang-error-handling skill.
**Apply to:** `llm_agent_finalize.go` (the finalize transport error path before stub fallback).
