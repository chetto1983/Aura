# Phase 07.1 Plan 03: Forced-Finalization Spine Summary

Added the forced-finalization spine (Req#2): `finalize()` in the new `internal/agent/llm_agent_finalize.go` issues ONE tool-free synthesis turn (`ToolChoice="none"`, full in-memory history + the D-03 nudge on a COPY), drains it to a `content` string (NOT `tool_calls`), and emits a NON-EMPTY `finalEvent` that still carries `termination_reason`/`limit_hit` for observability. Both early-termination sites in `llm_agent.go` (budget trip `:124`, dedup trip `:224`) now route through `finalize()` instead of dying on a prose-less `terminalBudgetEvent` — killing the ~1-in-6 empty-answer path.

## What Was Built

- **`internal/agent/llm_agent_finalize.go`** (NEW, 92 LOC — D-07 concern-split):
  - `finalizeNudge` constant — the D-03 synthesis instruction (English, no IT directive; `SystemPrompt` governs language). Load-bearing literal.
  - `finalize(ic, spanID, parentSpanID, requestID, reason, yield)` — appends the synthesized answer to `a.history` (mirrors the content-stop path) and yields ONE terminal `finalEvent`.
  - `synthesize(ic) (answer, usage, err)` — builds the request from a COPY of history + the nudge via `builder.Build(..., prompt.Budget{})` (zero-value omit sentinel — no `<budget>` tail), sets `req.ToolChoice="none"` + `req.SessionID`, calls `a.client.Stream` DIRECTLY (never spends a budget step — Req#4), drains the channel into a `strings.Builder` (Pattern C — no intermediate yields), wraps a transport error with `%w` for plan 04.
  - `finalizeEvent(...)` — builds on `finalEvent` (usage footer) then merges the `termination_reason`/`limit_hit` keys sourced from `terminalBudgetEvent` (landmine #10 — observability preserved on the non-empty terminal).
- **`internal/agent/llm_agent.go`** (MOD): budget trip (`:124`, covers max_steps + wallclock) and dedup trip (`:224`) now call `a.finalize(...)` and return, replacing the bare `yield(a.terminalBudgetEvent(...)); return`. Event-only, never the error slot.
- **`internal/agent/llm_agent_finalize_test.go`** (NEW): `TestFinalize_DedupTrip` (3 echo turns trip the window-3 ring, finalize consumes Stream call #4), `TestFinalize_MaxStepsTrip` (`MaxSteps=1`), `TestFinalizeWallclock` (injected clock past the deadline — name matches VALIDATION.md). Shared `assertFinalizedNonEmpty` checks non-empty content, NOT-Escalate-only, and the matching `limit_hit`/`termination_reason`.
- **`internal/agent/llm_agent_test.go`** (MOD): two pre-existing trip tests updated for the new behavior (see Deviations).
