# Phase 07.1: Agent-Loop Forced Finalization - Context

**Gathered:** 2026-06-03
**Status:** Ready for planning

<domain>
## Phase Boundary

Harden the leaf `LlmAgent.Run` loop (`internal/agent/llm_agent.go`) so it ALWAYS
yields a non-empty natural-language final answer — even when a run terminates
early on a `max_steps`/`wallclock` budget trip or a dedup-ring veto. The fix
wires four behaviours into EXISTING primitives (`finalEvent`,
`Budget.Remaining()`, `PromptBuilder.Build`, the OpenAI-compat wire), inventing
no new subsystem:

- **P0** `finalize()` tool-free synthesis (`tool_choice="none"`, parse `content`)
  at all three early-termination paths.
- **P0** `ToolChoice` threaded through `llm.Request` → `internal/llm/openai_compat`.
- **P1** counter-gated one-shot recovery turn on dedup + budget trips.
- **P2** `<budget>` used/remaining prompt block to curb fan-out.

Scope is the leaf `LlmAgent` ONLY. Swarm (Parallel/Sequential/Loop) finalization
semantics are Phase 9. The dedup-detection algorithm itself
(`budget_dedup.go`) is untouched — only the RESPONSE to a veto changes.

</domain>

<decisions>
## Implementation Decisions

### Nudge & synthesis wording (Req#2, Req#3)
- **D-01:** Both the recovery nudge and the finalize synthesis nudge are authored
  in **English** and carry **NO Italian directive** — `messages[0]`
  (`SystemPrompt`, `internal/agent/prompt.go`) already ends with
  `Always respond in Italian.`, which governs output language for every turn
  including the tool-free finalize turn. Repeating it would only add tokens.
  (Aligns with memory `feedback_all_prompts_in_english_only`.)
- **D-02:** Recovery nudge (`user` role, injected EXACTLY ONCE on the first trip):
  > "You have already called `{tool}` with these arguments and the result will
  > not change. Do not repeat any tool call — answer the user's question now
  > using the results you have already gathered."

  `{tool}` is the offending tool name from the dedup/budget trip. Wording is a
  starting point; planner may refine but MUST keep the "do not repeat / answer
  now from gathered results" intent and the `user` role.
- **D-03:** Finalize synthesis nudge (`user` role, sent with `ToolChoice="none"`):
  > "Stop calling tools. Using only the tool results already gathered above,
  > write the final answer to the user's original question now."

### `<budget>` block — threading + format (Req#6)
- **D-04:** **Threading via the builder chokepoint.** Extend
  `PromptBuilder.Build` (`internal/agent/prompt/builder.go`) to accept the
  used/remaining step counts and append the `<budget>` block to a **COPY** of the
  history slice. `a.history` MUST stay unmutated and `messages[0]` MUST stay
  byte-identical (D-01 single-chokepoint discipline + cache-prefix stability).
  Do NOT have the agent pre-mutate `a.history` with the block.
- **D-05:** The `<budget>` block is carried as a **tail `user`-role message**
  (the LAST message in the assembled request), NOT a system message. Rationale:
  OpenAI-compat wires expect `system` only at position 0; a trailing user message
  never risks prefix re-ordering or non-leading-system inconsistency across
  providers.
- **D-06:** **Format:** `<budget>used=N remaining=M</budget>` where
  `M = Budget.Remaining()` and `N = max_steps - M`. Plain, directional — exact
  arXiv % targets are explicitly out of scope.

### `finalize()` / recovery placement + counter (Req#2, Req#3, Req#4)
- **D-07:** `finalize()`, the recovery-turn logic, the retry, and the
  deterministic stub all live in a **NEW file
  `internal/agent/llm_agent_finalize.go`**. `llm_agent.go` is already 329 LOC;
  inlining would crowd it toward the 600-LOC no-god-class ceiling. The two
  termination call-sites in `llm_agent.go` (budget trip `:124-127`, dedup trip
  `:224-227`) call into the new file.
- **D-08:** The per-run recovery-attempt counter is a **field on `LlmAgent`**
  (e.g. `recoveryAttempts int`) — NOT on `Budget` (shared by pointer across the
  swarm tree per D-10; a counter there would leak recovery state between branches)
  and NOT on `InvocationContext`. It is a counter, NEVER a one-shot boolean latch
  (CrewAI #1656 anti-pattern, per SPEC constraint).

### Deterministic stub digest (Req#5)
- **D-09:** When `finalize()` returns empty/errors TWICE, emit a hardcoded
  **Italian** stub (no LLM in this path) as the `finalEvent` content:
  - Lead-in: `Non sono riuscito a completare la sintesi finale, ma ecco i dati che ho raccolto:`
  - Followed by one bullet per `RoleTool` result in `a.history`
    (`- {tool}: {preview}` with each preview truncated to ~500 bytes and a total
    cap), so the user always receives the gathered data even in the worst case.

### Claude's Discretion
- Exact byte caps for the stub digest (per-bullet ~500B / overall) and the
  precise final wording of the nudges — planner/executor may tune within the
  locked intent above.
- Whether the `Build` budget parameter is two ints, a small struct, or an
  optional pointer — an implementation detail left to planning, provided
  `messages[0]` byte-stability is preserved.

</decisions>

<code_context>
## Existing Code Insights

### Reusable Assets
- `finalEvent` (`llm_agent_events.go:62`): already builds the non-empty terminal answer Event with usage StateDelta — finalize/recovery/stub all emit through it.
- `Budget.Remaining()` (`budget.go:238`) + `branchConsumed`: expose the step accounting the `<budget>` block needs; no new accounting required.
- `PromptBuilder.Build` (`prompt/builder.go:26`): the single message-assembly chokepoint — the only place to attach the `<budget>` tail message cache-safely.
- `agenttest.FakeClient` + `TextChunks`/`ToolCallTurn`/`WithUsage`/`MakeToolCall`: a goleak-clean scripted client that records every `llm.Request`. `FakeTurn.Err` covers the "finalize errors on call 2" fallback test; empty chunks cover the "finalize returns empty" case. No new test harness needed.
- `wireRequest.ToolChoice string` (`openai_compat/client.go:58`, `omitempty`): the wire field already exists — only the plumbing above it (the `llm.Request` field + non-hardcoded assignment + tools-omission) is missing.

### Established Patterns
- **Byte-stable `messages[0]` / cache discipline:** every assembly path must keep `messages[0]` byte-identical (D-01/D-08/D-09; cache-poisoning sites mapped in memory `reference_aura_cache_poisoning_sites`). The `<budget>` block is the live test of this — it must tail-inject, never touch the prefix.
- **Budget trip = Event-only, never the `iter.Seq2` error slot** (D-04/D-15): finalize and recovery emit Events; only a real finalize *transport* failure (before the stub fallback) would use the error slot — and the guaranteed-answer contract means the terminal user-facing Event is always a non-empty `finalEvent`.
- **Backward-compatible wire serialization:** defaulting `ToolChoice` to `"auto"` when empty keeps all existing callers byte-identical (Req#1 acceptance).
- **`-race` + `goleak` + ≤600 LOC + golangci-lint=0** post-edit gate on every touched file.

### Integration Points
- New `internal/agent/llm_agent_finalize.go` ← called from the two trip sites in `llm_agent.go`.
- `llm.Request.ToolChoice` → `openai_compat.buildWireRequest` (wire) and ← set by `finalize()` (`"none"`).
- `PromptBuilder.Build` ← `LlmAgent.Run` passes `Budget` step counts each turn.

  at the source (e.g. dropping "more results may be available" hedges). Out of
