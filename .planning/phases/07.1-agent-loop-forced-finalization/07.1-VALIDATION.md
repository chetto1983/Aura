| Property | Value |

## Sampling Rate

- **After every task commit:** Run `go test ./internal/agent/... ./internal/llm/... -count=1`
- **After every plan wave:** Run `go test -race ./internal/agent/... ./internal/llm/...`
- **Before `/gsd-verify-work`:** Full suite + `scripts/coverage_gate.sh` green (owned-surface ≥85%); mutation spot-check ≥70% on `llm_agent_finalize.go` (WSL `go-mutesting`)
- **Max feedback latency:** ~15 seconds (unit+race)
