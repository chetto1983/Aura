# Phase 07.1 Plan 05: Live tool_choice=none Smoke + meteo-Caraglio E2E Summary

Added the two LIVE, env-gated, operator-authorized tests that close ACs 4 and 9 against the REAL DeepSeek-V4/OpenRouter endpoint — the actual non-deterministic repro this phase exists to fix. `internal/agent/live_finalize_test.go` lives under a NEW `live_finalize` build tag (the `internal/agent` package had no live tag) and is gated on `OPENROUTER_API_KEY` (plus `SEARXNG_URL` for the web-tool E2E): both tests `t.Skip` locally without the key (the one legitimate local skip) but `t.Fatal` under `$CI` (no-skip-as-green). The file is excluded from the default lane entirely (no tag → not compiled), so it never runs in normal CI / `make quality` and incurs no accidental paid calls.

## What Was Built

- **`internal/agent/live_finalize_test.go`** (NEW, 309 LOC):
  - **`TestLiveToolChoiceNone` (AC4)** — mirrors the production `synthesize()` path one-shot: builds a finalize-shaped history (system + user question + assistant `web_fetch` tool-call + tool-result + the `finalizeNudge`), runs `prompt.NewPromptBuilder().Build(...)`, sets `req.ToolChoice = "none"`, Streams the REAL client, drains `content`, and asserts (a) `content` is non-empty AND (b) the prose does not STRUCTURALLY parse as a tool-call object (`toolCallShapedLeak` — `tool_calls` key or `name`+`arguments` pair, checking the whole content or a fenced ```json block; no NLP phrase-matching).
  - **`TestLiveMeteoCaraglio` (AC9)** — drives the exact Phase-7 repro prompt `"dammi le previsioni meteo a Caraglio"` through the REAL `LlmAgent.Run` + REAL web tools (`web_search`/`web_fetch` over one live `web.Client` engine) `meteoRuns`=6 consecutive times; asserts EVERY run's terminal Event (the FINAL Event, `FinishReason` set) has non-empty `LLMResponse.Content` and the observed failure rate == 0.
  - Gating helpers `requireLiveKey` (key → skip/`t.Fatal`) + `requireLiveEnv` (SEARXNG_URL, same shape), `loadLiveLLM` (`llm.Load`), `registryForLive` (mirrors `cmd/aura` `buildRegistry` web wiring), `runMeteoOnce` (one full Run, returns terminal content), `drainContent`, and the structured-leak pair `toolCallShapedLeak`/`jsonObjectCandidates`.
