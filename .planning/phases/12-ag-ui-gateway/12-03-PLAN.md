<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local HTTP client → `POST /agent/run` | Untrusted-ish local JSON crosses here. Size-limited, content-validated, malformed-JSON-rejected. UNAUTHENTICATED by design this phase (auth deferred) — the control is the loopback bind. |
| local HTTP client → `GET /threads/<id>/messages` | Thread-id is the access chokepoint (`conv.Get`); single-user `local` v1, no cross-identity isolation yet. |
| agent error → SSE RUN_ERROR | Internal error strings could leak DSN/key/path onto the wire. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-08 | Elevation of Privilege | unauthenticated endpoint exposed beyond loopback | mitigate | Bind hardcoded `127.0.0.1:9080` via config default; no `--bind` flag this phase; auth deferred but documented (Pitfall 6 / amendment #35). The loopback bind IS the compensating control. |
| T-12-09 | Denial of Service | slow-client SSE (slow-loris) | mitigate | cap-64 buffered SSE pump + drop-with-WARN + RUN_ERROR if persistent (never block the Loop); `http.Server` ReadHeaderTimeout/WriteTimeout-class bound on the daemon. |
| T-12-10 | Information Disclosure | RUN_ERROR message | mitigate | Sanitize the surfaced `err.Error()` — never echo DSN/key/internal path; agent path already structurally redacts keys (D-28). |
| T-12-11 | Information Disclosure | cross-thread history read | mitigate | `conv.Get` is the chokepoint; unknown thread → 404 (not 403 — no identity to authorize against yet). Single-user `local` v1. |
| T-12-12 | Tampering / DoS | malformed/oversized request body | mitigate | `http.MaxBytesReader` (fixed cap) → 400; SDK `UnmarshalJSON` rejects bad shapes → 400; `ValidateRunInput` rejects empty threadId/messages. |
| T-12-13 | Spoofing/Tampering | CSRF from a malicious local web page | mitigate | Restrictive CORS by default (`Access-Control-Allow-Origin: *` only behind `AURA_AGUI_CORS_PERMISSIVE`); loopback-only bind reduces blast radius. |
</threat_model>
