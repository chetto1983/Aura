## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `internal/agent` → `internal/agui` | One-way import only. `internal/agent` MUST NOT (transitively) import `internal/agui`. CI-enforced via `go list -deps` closure check (D-17). |
| untrusted `*agent.Event` content → AG-UI wire | The translator forwards LLM/tool content onto the wire. Empty/invalid ids and deltas must be rejected/skipped before reaching `Validate()`. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-12-02 | Tampering | SDK supply chain | mitigate | Pseudo-version pin `v0.0.0-20260514093510-e9e910b230b9` is immutable via go.sum; CI greps the literal (exactly 1 match). A swapped commit changes the hash and breaks the build. |
