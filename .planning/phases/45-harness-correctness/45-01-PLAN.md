<assumption_delta_decision>
**Noun that is now primary:** the *generalized operation identity* — an operation is identified by
`(parent scope, parent key, parent fingerprint, tool scope, tool fingerprint, round ordinal)`.
The previous noun (turn-scoped operation identity, no round) is the special case where the round
ordinal happens to be 1.

**Decision: `promote`.**

Rationale: the round ordinal is not an extra attribute bolted onto the old identity — it is the
axis that makes the identity correct. The old, round-less identity is demoted to "the value the
generalized identity takes on round 1", and `Version` moves to `tool-child-v2` to document that the
general representation is now primary. Adding a second, parallel key shape alongside the old one
would contradict the generalized intent and reintroduce F-1 on whichever path kept the old shape.

**Invariant test encoding the generalized intent** (authored in plan 45-02, task 2): the derived
child operation key MUST be equal for two derivations at the same round and MUST differ for two
derivations at different rounds, with all other inputs held identical. A future phase that
reintroduced the singular (round-less) assumption turns that test red.

**Pre-flight grep, run at planning time (2026-08-13), recorded so plan 45-02 re-verifies rather
than assumes:** `grep -rn "tool-child-v1\|FingerprintTyped" internal/ --include=*_test.go` returns
**no match on the `"tool-child-v1"` literal anywhere**. `FingerprintTyped` appears in 8 test files
