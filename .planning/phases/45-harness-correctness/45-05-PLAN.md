the rule that planning, self-critique and tool reasoning never leak into user-facing text.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent → operator (user-facing reply text) | The reply is the operator's only view of what happened; a turn that claims completion for work that did not run is a trust failure, not a formatting one |
| critic model → agent loop (veto decision) | A second model's judgement gates whether the turn may end; it must be able to fail without blocking the turn |
| system prompt → provider cache prefix | `messages[0]` bytes are the cache key prefix; volatile content there is a measured, recurring cost |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-18 | Repudiation | a turn ending on a stated-but-unexecuted intention | mitigate | Dropping `!a.sideEffected` routes exactly that turn shape through the critic, which judges by tool results and never by the agent's claims; the second nudge forces the turn to name what did not run |
| T-45-19 | Denial of Service | an unbounded critic veto loop stalling the turn | mitigate | The attempts bound moves 1 → 2 and no further; Task 1 asserts a third attempt is accepted regardless of the critic's verdict |
| T-45-20 | Denial of Service | critic unavailability blocking every turn | accept | Fail-open is deliberate and unchanged — a critic error, timeout or missing model lets the turn end. The residual is that an unkept intention can slip through while the critic is down; that is the accepted trade, and `cfg.CompletionCriticModel` keeps the critic cheap enough to stay up |
| T-45-21 | Information Disclosure | internal deliberation, tool-selection reasoning or self-critique leaking into user-facing text | mitigate | A static `messages[0]` rule (D-21). Verified live under ACC-01, not by a gate — the honest disposition, since no detector exists in Aura or hermes and a fabricated automated check would be worse than none |
