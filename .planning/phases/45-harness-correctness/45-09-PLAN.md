<objective>
Close SC#5, which 45-08 proved open on the running stack: raw deliberation reached the
user-facing channel, in the wrong language, carrying invented fact_key values that the
model itself admitted to fabricating in the same visible text.

The system-prompt rule shipped by 45-05 (D-21) is present in the running binary and did
not hold. This plan adds the enforcement the phase assumed the prompt would provide.
</objective>

<context>
Measured 2026-08-15 against build `ed252f6b6`, model `deepseek/deepseek-v4-flash-0731`
(OpenRouter), conversation `01a004e0-843f-764e-9272-e6327a130a27`. Full evidence in
`45-VALIDATION.md` §"Task 2 — Live Run: Results", including the per-channel phrase counts
that rule out a parser artefact.

Three defects in ONE turn, all user-facing:
1. leaked self-critique ("Hmm, wait", "OK stop", "Let me be careful");
2. a language break — the leak was English, to an operator writing Italian, mid-reply;
3. fabricated `fact_key` values presented as real, then admitted as invented.

(3) is the one that matters most: it is the same class of harm as the unlabelled replay
this whole phase was built to eliminate — a value shown to the operator that was never
recorded.
</context>
