<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| iterator frame ↔ sub-agent stream | every yield must be guarded; a bare yield after false panics |
| loop iteration ↔ shared dedup ring | LoopAgent must share the ring across iterations or cross-iteration loops never detect |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02 | Denial of Service | runaway loop not detected (dedup ring not shared across iterations) | mitigate | LoopAgent uses `WithSubAgent` (shared ring, D-09), NOT `Child` — cross-iteration repeats fire; caller canonicalizes args (B2) so the fingerprint is stable; proven by `_DedupWindow_TerminatesOn3SameToolCalls` |
| T-02-11 | Denial of Service / panic | bare `yield` after it returned false (iter.Seq2 footgun 2) | mitigate | every yield is `if !yield(...){ return }` (D-22); race + goleak tests exercise early-return paths |
| T-02-12 | Tampering | termination signalled via error slot pollutes real-failure channel | mitigate | budget exhaustion is Event-only (D-04); `error` slot carries only real LLM/tool failures; `ErrBudgetExhausted` sentinel for out-of-stream consumers |
</threat_model>
