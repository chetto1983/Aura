# Phase 08.2 Plan 04: internal/activelearn extraction + reasoning live floor raise Summary

Extracted the shipped `reasoninglearn.Learner` async skeleton into a label-agnostic `internal/activelearn` core (bounded queue + sha256 content-hash dedup + `sync.Map` seen-set + margin gate + non-blocking drop-on-full + one bounded goleak-clean goroutine + once-guarded `Close`), made the observation OPAQUE via an `Oracle.LabelAndSave(ctx, text, vec) (saved bool)` seam so the core imports neither `prompt` nor a tool type (D-05, Open-Q #4). Refactored `reasoninglearn.Learner` ONTO this core behavior-preserving — its `prompt.ReasoningTier` Oracle/Saver signatures, its `New(cfg)/Observe/Close` API, and its `prompt.Learner` satisfaction are all unchanged; a `reasoningOracle` adapter folds `Label+tier.Valid()+Save` into the opaque `LabelAndSave`, preserving the exact `seen.Delete`-on-failure retry. Then, sequenced AFTER the Plan-02 behavior-equivalence proof, raised `TestReasoningClassifierLive` (tag `reasoning_live`) from the shipped 80/88 floor to 90/92 (D-04 amendment) and did additive seed/anchor tuning to meet it on the 24-prompt live Italian corpus. The full unit corpus + the Plan-02 equivalence test both stay green — the automated non-regression proxy that the floor was earned, not bumped.

## Deviations from Plan

### Auto-fixed / unblock

**1. [Rule 1 - Bug] Synthetic `vecFor` keyword map out of sync with the new seeds (test-fixture fix)**
- **Found during:** Task 2, running the deterministic unit corpus after the additive seed tuning.
- **Issue:** The new low/high seeds (`"quando parte il prossimo treno..."`, `"come e finita la partita..."`, `"c'e traffico in autostrada..."`, `"ottimizza questo algoritmo..."`, `"analizza questo stack trace..."`, `"crea una pipeline di build e test..."`) contain keywords the synthetic `vecFor` did not recognize, so they collapsed onto the `[1,0,0]` none axis and polluted the none centroid — flipping `TestReasoningClassifier_FoldsStoredExamples` (`base=high learned=high`, expected `none`). This is a fixture-completeness bug (the fake embedder must embed the seeds it folds onto orthogonal axes), surfaced by the new seeds.
- **Fix:** Extended the `vecFor` keyword allowlist so each new seed maps to its correct one-hot axis (`treno/partita/traffico/autostrada → low`; `ottimizza/algoritmo/stack trace/pipeline/build → high`). This is NOT a weakening of any assertion — every committed deterministic verdict (the full unit corpus + the Plan-02 equivalence golden table) is identical after the sync; the new keywords do not collide with any existing test input. T-08.2-14 (the constant-bump-without-tuning threat) is mitigated precisely because the proxy unit+equivalence corpus stays green only when the tuning is real.
- **Files modified:** `internal/agent/prompt/reasoning_classifier_test.go`.
- **Commit:** 419a39fd.
