# Phase 08.2 Plan 01: Reusable semindex embedding-index core Summary

Extracted `internal/semindex` — one lock-free pure-math core (cosine/l2normalize/centroid/margin over `[][]float64`, lifted verbatim from `reasoning_classifier.go`) plus two typed wrappers, `Classifier` (Centroid: argmax → best label + top-2 `Margin`) and `Ranker` (PerItem: top-K cosine → `[]Scored`, incremental append), each holding the owned `Embedder` seam and one `sync.RWMutex`; brute-force only, no ANN, `-race`-clean at 92.1% coverage. This is the foundation waves 2/3/4 import.

## What Was Built

### Task 1 — pure math core + owned Embedder seam (commit eec73cfe)
- `core.go`: `l2normalize` / `cosine` / `centroid` lifted **verbatim** from `reasoning_classifier.go:218-264` (renamed `cosineSimilarity`→`cosine`, `meanNormalize`→`centroid`); the `-2.0` "impossible cosine" sentinel preserved for len-mismatch (T-08.2-01, never panics). Added `margin(scores []float64) float64` = the top-2 argmax-with-second sweep (lifted from lines 155-169), seeded at `-2.0` so a single score yields `best-(-2.0)`. **No `sync`, no `context`, no ANN import** (Req-8 brute-force-only).
- `semindex.go`: package doc + the owned `Embedder` interface (byte-identical to `documents/embedder.go:29` — the no-adapter claim) + `Scored{Label,Score}` (the bm25 `scoredDoc` analog, exported with a label) + `Verdict{Label,Score,Margin,Ok}`.
- `core_test.go`: table-driven golden tests of `cosine` (identical/orthogonal/opposite/45°/len-mismatch sentinel/empty), `l2normalize` (unit-norm + zero-vector unchanged), `centroid` (nil on empty bank — T-08.2-03, one-hot mean normalized), `margin` (clear/unsorted/single/empty/tied/negative), and an end-to-end golden-margin over synthetic one-hot vectors. All parallel, deterministic.

### Task 2 — Classifier + Ranker typed wrappers (commit 48987033)
- `classifier.go` (Centroid mode): per-group raw-exemplar bank (`map[string][][]float64`) + memoized per-group centroids + one `sync.RWMutex`. `AddVecs(label, vecs...)` / `Add(ctx, label, texts...)` write-lock-append exemplars and invalidate that group's centroid; `RankVecs(vec)` / `Rank(ctx, text)` return a `Verdict` with best label + score + top-2 `Margin`. Mirrors the `ensureAnchors` "build failure NOT cached → self-heals" discipline (nothing is added on embed error; a retry succeeds). Deterministic argmax tie-break via sorted labels.
- `ranker.go` (PerItem mode): append-only `[]Item` bank + one `sync.RWMutex`. `AddVecs(items...)` / `Add(ctx, texts...)` write-lock-**append** (the D-03 incremental door); `Len()` exposes bank size; `RankVecs(vec, k)` / `Rank(ctx, query, k)` return `[]Scored` top-K via core `cosine`, using `sort.SliceStable` desc with an **insertion-index tie-break** (copied from `bm25.rank` — load-bearing for top-K stability). `k<=0` or `k>bank` returns all. `Rank` carries the embedder error on `RankResult.Err` (Req-6). **No `Margin`.**
- `semindex.go`: added `Item{Label,Vec}` for the PerItem bank.
- `testhelpers_test.go`: the `fakeEmbedder` (call-counter + `failUntil` + `failQuery`) copied verbatim from `reasoning_classifier_test.go:15-37` + a synthetic one-hot `vecForGroup` mapping.
- Wrapper tests: Classifier argmax + golden margin (0.2 over a tilted query), Add-folds-centroid, text-in embeds query, embed-failure surfaces error, build-failure-not-cached recovery, empty-bank not-ok, concurrent Add+Rank `-race`. Ranker top-K-by-cosine, deterministic tie-break (20 trials), incremental-append (bank grows by exact count, prior items still rank), text-in Add, embed-error surface, empty-bank empty, k>bank/k<=0 return-all, concurrent Add+Rank `-race` (RESEARCH risk #5).

## Notes for Downstream Plans

- **Wave 2 (tool ranker):** import `semindex.Ranker`. Feed `searchDocument(spec)` (the bm25-doc, D-02) as the `Add` text; `Add` labels each item by its source text — for tools you will likely want `AddVecs(Item{Label: toolName, Vec: ...})` instead so the result label is the tool name, not the search-doc. The append-only bank + `Len()` are the D-03 incremental-mount door (embed only newly-advertised tools and append; the `RWMutex` keeps rank consistent under concurrent mount+search).
- **Wave 4 (reasoning migration):** `reasoning_classifier.go` delegates to `semindex.Classifier` (Centroid). `prompt.Embedder` becomes `type Embedder = semindex.Embedder` (alias only — per PATTERNS.md cascade-break warning, do NOT relocate `LabeledVec`/`ExampleStore`/`Learner`, which `reasoningstore`/`reasoninglearn` import from `prompt`). The Classifier's per-group bank maps the `anchors map[ReasoningTier][]float64`; tier labels become string keys.
- **Embedder error surface:** the wrappers surface the embedder error verbatim (Classifier `Rank` returns it; Ranker `Rank` carries it on `RankResult.Err`). This is the seam wave 2 uses to satisfy Req-6 (explicit model-visible `ToolResult` error on embed-sidecar-down, never an empty ranking).
- **COW deferred (D-01):** both wrappers use a plain `RWMutex`. The concurrent `-race` subtests pass; adopt copy-on-write only if a later benchmark shows read-lock contention (RESEARCH risk #5).
