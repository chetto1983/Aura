## semindex API shape

The first AskUserQuestion (one generic Index + alias / core + typed wrappers / vector-in-out)
was answered **"deep search online best industrial pattern and validate with test"** → a
research agent surveyed kelindar/search, chromem-go, langchaingo, Go Proverbs, and Anthropic's
tool-search-with-embeddings cookbook. Re-presented with the evidence-backed shape:

| Option | Description | Selected |
|--------|-------------|----------|
| Lock research-backed shape | Unexported pure core (bank+cosine+centroid+margin over [][]float64, lock-free) + two exported wrappers Classifier/Ranker each holding Embedder + sync.RWMutex; vector-in (AddVecs/RankVecs) + text-in doors for synthetic-vector golden-margin tests; documents.EmbeddingClient = Embedder no adapter | ✓ |
| Single generic Index instead | One Index + mode param (Centroid\|PerItem) as originally proposed; research flagged as the "weak abstraction" anti-pattern | |
| Keep researching | Spike a throwaway prototype of both shapes before locking | |

**User's choice:** Lock research-backed shape (after directing the research).
**Notes:** Resolves the reuse-vs-segregation tension — shared math at the unexported core,
two focused public surfaces. Vector-in doors are the test-validation lever the operator asked
for. Rejects the single `mode`-enum god-type (CLAUDE.md NO-GOD-CLASS + Go interface segregation).

## Learned-example influence + Neo4j

First AskUserQuestion (per-tool centroid guarded boost / kNN exemplar-as-doc / keep researching)
was answered **"Keep researching"** → a research agent surveyed Stanford IR (Rocchio, kNN),
prototypical networks (Snell 2017), confirmation-bias (Arazo 2020), and safe-LTR (PRPO/SEA).
Re-presented with the refined mechanism + three research-added guards:

| Option | Description | Selected |
|--------|-------------|----------|
| Lock refined mechanism | Per-tool positives-only Rocchio centroid via semindex.Classifier(Centroid), stage-2 margin-gated boost (α≥β) + min-support floor N≥3-5 + boost cap ≤ε·desc_cos + seeds authoritative + dedup + bounded bank + oracle-in-loop; multimodal split deferred; Neo4j :ToolSelectionExample | ✓ |
| Lock + multimodal split now | Same but also implement k≤2 sub-prototype split this phase (against minimal-shape lean) | |
| Lock without min-support/cap | Plain centroid + margin-gated boost without the research-added guards | |

**User's choice:** Lock refined mechanism (after directing the research).
**Notes:** Research confirmed "centroid not kNN" and added three guards the spike missed
(min-support floor = highest value; boost cap = PRPO ε-bound; multimodal suppress-on-variance).
Key safety framing: the loop trains on oracle ground-truth, not self-pseudo-labels → structurally
not classic confirmation bias, provided the ranker never self-confirms.
