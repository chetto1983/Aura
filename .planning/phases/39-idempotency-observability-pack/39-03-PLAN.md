<threat_model>
## Trust Boundaries

| Boundary | Risk | Control |
|---|---|---|
| Unauthenticated probe caller -> dependency errors | Readiness leaks topology, credentials, or driver details. | Public output is stable codes only; detail is internally redacted/logged. |
| Probe traffic -> databases | Slow polling exhausts connections/goroutines. | Concurrent probes share one short deadline and all goroutines join. |
| Background server/scheduler -> root process | Fatal runtime failure is hidden while traffic continues. | Joined lifecycle propagation plus fail-closed snapshot. |
| Compose -> daemon | Wrong endpoint or timeout marks unsafe service healthy. | Semantic artifact test pins loopback `/readyz` and budget ordering. |

ASVS L1 controls: minimal unauthenticated output, timeout/resource bounds, fail-safe defaults, and explicit error handling. Information leakage, readiness false-positive, or unjoined fatal worker failure is high severity and blocks completion.
</threat_model>
