<threat_model>
## Trust Boundaries

| Boundary | Risk | Control |
|---|---|---|
| Arbitrary observation -> memory cache | Cardinality/memory exhaustion or raw-content retention. | Hash-only values, 100k hard cap, 30d TTL, bounded queue/admission. |
| Neo4j -> process load | Unbounded query/startup memory exhaustion. | Server-side age/source/order/LIMIT and hard result validation. |
| Quality/novelty input -> compaction | Poisoned scores force attacker-selected retention. | Clamp fields, reserve newest fraction, deterministic bounded selection, pinned seeds isolated. |
| Compactor -> learned graph | Partial/overlapping deletes remove protected seeds or race writes. | Source/version predicates, non-overlap, bounded batches, idempotent rerun. |

ASVS L1 controls: resource quotas, strict enum/range validation, data minimization, bounded background work, safe cancellation, and no sensitive telemetry. Unbounded loads/cache, raw text in dedup memory/metrics, pinned-seed deletion, or cap bypass is high severity and blocks completion.
</threat_model>
