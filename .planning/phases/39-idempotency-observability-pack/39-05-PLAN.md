<threat_model>
## Trust Boundaries

| Boundary | Risk | Control |
|---|---|---|
| Metrics/traces -> operator stack | Sensitive labels/content are retained or queried. | Catalog allowlist validation and content-free dashboards/alerts. |
| Host/network -> Prometheus/Tempo | Unauthenticated ingestion/scrape endpoints leak or accept data. | Internal Compose network; no default host publication; explicit opt-in UI only. |
| Container registry -> deployment | Mutable/compromised images change behavior. | Official images pinned by full digest and checked in CI. |
| Rules/dashboards -> incident response | Precision or link drift causes false pages/missed incidents. | Boundary fixtures, stable UIDs, bidirectional link/runbook verification. |

ASVS L1 controls: secure configuration, least network exposure, immutable dependencies, no embedded secrets, safe diagnostics, and integrity validation. Public ingestion exposure, unpinned images, secret-bearing telemetry, or untested paging semantics is high severity and blocks completion.
</threat_model>
