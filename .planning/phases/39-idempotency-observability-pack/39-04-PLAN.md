<threat_model>
## Trust Boundaries

| Boundary | Risk | Control |
|---|---|---|
| User/remote values -> telemetry attributes | Secret leakage and cardinality/resource exhaustion. | Finite enum allowlists, `other` fallback, no content/identity identifiers. |
| Metrics listener -> network | Unauthenticated operational data becomes public. | Dedicated registry and loopback/internal listener by default; no AG-UI mount. |
| Exporter failure -> daemon | Telemetry outage takes down core service or hangs shutdown. | Failure isolation, bounded queues/timeouts, reverse-order deadline shutdown. |
| Legacy -> OTel migration | Duplicate series corrupt alert ratios and cost. | Single owner per logical metric and overlap/double-emission tests. |

ASVS L1 controls: sensitive-data minimization, strict attribute validation, least exposure, bounded resource usage, and safe failure. Public scrape exposure, content leakage, unbounded labels, or duplicate canonical series is high severity and blocks completion.
</threat_model>
