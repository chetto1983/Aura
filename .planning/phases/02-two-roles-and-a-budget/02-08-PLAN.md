<objective>
Build the cockpit half: an identity roster with a destructive removal behind a typed
confirmation, a per-identity credit panel that shows cap, remaining and spend from Aura's own
ledger, a three-phase creation wizard with the capability picker deleted, and the zero-credit
refusal copy in the chat error slot that is currently empty.

Purpose: RBAC-11 is "the cockpit creates an identity and removes one without leaving the UI", and
the removal leg has no control at all today. But the more urgent item is smaller and easy to miss:
`useAdmin.ts` derives `isAdmin` from `governance.write`, and under D-01 every identity holds
`governance.write`. The moment plan `02-01` lands, every user in the deployment sees the admin
surface. The server still refuses them, so it is not a breach — it is a cockpit that shows
controls it will then reject, which is worse than either alternative.

Output: `IdentityRoster.tsx` replacing `CapabilityAdminPanel.tsx`, `CreditPanel.tsx`, a shortened
wizard, deleted dead components, and the admin-derivation fix.
</objective>
