<objective>
Make the refusal real and close the fallback. A turn by an identity with no credit stops before
the model is called, with a machine-readable reason a human can act on; an identity with no key
is refused rather than billed to the operator; a local backend says it is exempt rather than
showing zero; and every path in the tree that builds an agent gets its credential from the
turn's identity.

Purpose: the cap is only worth what the fallback is not. `internal/swarm/swarm.go:290` and
`internal/cron/handlers/handler.go:126` both read `client, cfg := rc.Client, rc.LLM` first and
override from the runtime port only `if rc.Runtime != nil` — so a nil port silently spends the
deployment key. That is a fail-open path reachable by a missing field, and no test of the happy
path can see it. This plan closes it and leaves behind a test that goes red if it comes back.

Output: a pure credit-decision file, a `creditExhaustedClient` sentinel beside the one this
codebase already ships, `cmd/aura/llm_client_test.go` (which does not exist today — a Wave 0
gap `02-VALIDATION.md` names), and an invariant test over every agent-construction site.
</objective>
