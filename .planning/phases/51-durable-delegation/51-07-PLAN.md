    - `ListChildTranscripts(conv)` returns the child ids that have a transcript file for that conversation, empty slice when none, never an error for a missing directory.
    - `ReadTranscript(conv, childID, fromOffset)` returns the bytes written so far plus the new offset, and returns immediately even while the worker is still running (no blocking, no wait-for-EOF).
    - A `childID` or `conv` containing `..`, `/`, `\`, or a NUL byte is rejected before any filesystem call — the resolved path must remain under `$AURA_RUN_DIR`.
    - The HTTP route returns 404 (not 403 with detail) for a conversation the caller's identity does not own, and 200 with `application/x-ndjson` otherwise.
    - Offsets are monotonic: two sequential reads with the returned offset never duplicate or skip a line.
  </behavior>
