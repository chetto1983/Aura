<objective>
Implement the termination model **D-03 actually decided**, which the rest of this phase has so far
only sized a lease against.

D-03 was closed by measurement, and the measurement is unambiguous. PRD Amendment #154: *"the
termination model: **a wall-clock cap is the wrong instrument**. Four workers on executable goals
finished in 5.15 / 5.51 / 7.58 / 7.80s against a 120s cap — a 23× margin… Across three runs the
cap fired **once**, and what it caught was an OpenRouter `context deadline exceeded` — an upstream
stall, not slow work — while the worker genuinely worth interrupting (70.31s spent calling tools
that could never succeed) sailed under it and returned `ok`. **Both references reap on inactivity
rather than age, and Aura already owns the event loop where the tick belongs** (`runChild`,
`swarm.go:185`)."* And `51-CONTEXT.md` D-03 states the consequence for this phase directly:
*"with background delegation a hard 120s ceiling makes the background nearly pointless."*

Up to this plan, every D-03 citation in the phase is **lease sizing only** — the 51-01
prohibition, `AURA_SWARM_DELEGATION_LEASE_SEC=300`, the ≥240s criterion. The wall clock itself is
untouched: `internal/swarm/swarm.go:124` `childTimeout := time.Duration(rc.Cfg.SwarmChildTimeoutSec)
* time.Second` and `:139` `context.WithTimeout(egCtx, childTimeout)`. Plan 51-01 names that as an
**INTERIM** bound and points here. This plan is where it is replaced.

Both readings of "leave it alone" are defects, and this plan closes both:
- Keep the wall clock and a backgrounded delegation dies at the ~240s effective cap (nominal
  120s, doubled because a budget trip severs the expired deadline and the recovery call is then
  bounded by `AURA_LLM_TOTAL_TIMEOUT_SEC`), so "stops holding the operator's turn hostage" buys
  the operator four minutes.
- Remove it with nothing in its place and a stalled worker is never terminated at all — the
  event-sourced heartbeat then lets the *row* be reclaimed while the original goroutine keeps
  running: **two live workers on one goal.**

Decisions carried: **D-00** (hermes read before designing — `async_delegation.py`'s progress-based
staleness monitor is the reference, and Amendment #154 notes both references reap on inactivity),
**D-03** (the whole plan), **D-01** (the lease this deadline must stay under belongs to the
generic queue), **D-14** (one single Phase 51).

Purpose: make "the work is done when it is done" true instead of "done, or four minutes,
whichever comes first". Output: one staleness helper, one knob in, one knob out, one boot gate.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker event stream → its own liveness decision | a worker's own output is what keeps it alive: anything that can make a worker emit can make it immortal |
| inactivity deadline ↔ delegation lease | two independent bounds on the same work; if they cross, the queue hands one goal to two live workers |
