<objective>
Move the steer inbox from in-memory to Postgres with a TTL (**D-06**, operator decision), as ONE
table whose rows are typed by kind with two TTLs and one sweep (**D-07**), where an expired row
always leaves a readable trace written in the same transaction that expires it (**D-08**).

This is what makes the tracer's delivery durable: `internal/steer` is documented in-tree as
"in-memory, single-replica-by-construction" and "a steer is consumed by Drain, never replayed",
so a background completion pushed while no turn is running — the normal case for a delegation
that outlives its parent turn — is silently lost today. SC#1 forbids that.

**Scope note the ROADMAP does not account for (D-14):** this REOPENS `internal/steer`, Phase 52
code merged 2026-08-25. Legitimate under CLAUDE.md's fix-on-touch rule, named here so no
executor discovers it. It also retires amendment #133's single-replica boundary note.

Purpose: durability for the delivery half of SC#1. Output: one migration, one Postgres store
behind the unchanged `SteerInbox` seam, one TTL sweep.
</objective>
