## Trust Boundaries

| Boundary | Description |
|---|---|
| model -> memory_recall | Untrusted query, cursor, mode, and limits enter the retrieval API. |
| host context -> HTTP header -> MCP | Host-derived active conversation crosses process/transport boundaries. |
| ArcadeDB -> model evidence | Stored text and graph metadata re-enter model-visible output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-4903-01 | Spoofing | identity/active conversation | high | mitigate | OAuth subject remains identity; active conversation is host-only HeaderFunc state and only an exclusion filter. |
| T-4903-02 | Information Disclosure | cross-identity/active-context recall | high | mitigate | Fail-closed identity predicates, whole-active-conversation exclusion, and live isolation tests. |
| T-4903-03 | Tampering | cursor/mode/limit | medium | mitigate | Typed enum validation, opaque signed/bounded cursor state, deterministic clamping, and invalid-input tests. |
| T-4903-04 | Elevation of Privilege | stored prompt injection | high | mitigate | Typed provenance, bounded evidence, no instruction authority, and no execution of recalled text. |
| T-4903-05 | Repudiation | claimed retrieval path | medium | mitigate | Derive response and OTel path from the same executed-backend record and compare them live. |
| T-4903-06 | Denial of Service | broad hybrid search/window expansion | medium | mitigate | Per-tier candidate caps, bounded window/limit/cursor validation, and latency assertions. |
</threat_model>
