## Trust Boundaries

| Boundary | Description |
|---|---|
| model/client -> memory_batch | Untrusted ordered operations, targets, values, and idempotency key enter a mutating API. |
| batch compiler -> ArcadeDB transaction | Authorized typed operations become isolated working-state mutations. |
| concurrent clients -> shared graph | Conflicting batches race over identity-scoped facts/entities. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-4906-01 | Spoofing | batch identity/actor | high | mitigate | Authenticate identity and host-derive actor; schema contains neither field; enforce identity in every target lookup. |
| T-4906-02 | Tampering | partial/intermediate state | high | mitigate | Isolated working state, final-only validation, one transaction/commit, and no partial observer tests. |
| T-4906-03 | Repudiation | ambiguous retry | high | mitigate | Identity-bound idempotency key/request hash and durable committed result replay. |
| T-4906-04 | Elevation of Privilege | foreign target/worker authority | high | mitigate | Up-front operation authorization plus existing fact authority checks inside the same transaction. |
| T-4906-05 | Denial of Service | oversized/conflicting batches | medium | mitigate | Operation/payload bounds, transaction deadlines, optimistic retry cap, and deterministic first-error exit. |
| T-4906-06 | Information Disclosure | error/result surface | medium | mitigate | Return bounded typed final results and unchanged safe errors; never expose intermediate or foreign state. |
