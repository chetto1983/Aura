## Trust Boundaries

| Boundary | Description |
|---|---|
| PostgreSQL -> projection worker | Authoritative per-identity conversation data enters an asynchronous process. |
| projection worker -> ArcadeDB | Derived text, embeddings, identity keys, and tombstones cross databases. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-4902-01 | Spoofing | projection identity | high | mitigate | Derive identity from caller context/source rows; never accept model-supplied identity; assert foreign reads/writes are empty. |
| T-4902-02 | Tampering | derived source keys | high | mitigate | Stable `(identity, conversation, seq)` keys, content hashes, idempotent upserts, and PostgreSQL-driven reconciliation. |
| T-4902-03 | Information Disclosure | conversation content | high | mitigate | Eligible-role allowlist, secret redaction, active-context suppression deferred to recall, and per-identity graph predicates. |
| T-4902-04 | Denial of Service | projection queue/backend outage | medium | mitigate | Bounded ordered queue, retry/backoff, lag telemetry, and fail-soft turn completion. |
| T-4902-05 | Repudiation | edit/delete propagation | medium | mitigate | Direct source refs, high-water/counter telemetry, deterministic reconciliation, and live lifecycle tests. |
</threat_model>
