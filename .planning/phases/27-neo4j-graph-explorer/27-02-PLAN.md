## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/graph/* | Untrusted HTTP crosses into the daemon; RequireAuth (whole-origin, Phase 24) gates it; the body is a structured intent, size-capped |
| handler → GraphView | The handler passes a validated `GraphIntent` to the plan-01 normalizer; it never builds Cypher itself |
| daemon → mcp-neo4j-cypher | The boot-time `knowledge.Client` subprocess (read-tx enforced); its Close is in the reverse teardown |

## STRIDE Threat Register (ASVS L1, block on high)

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-03 | Spoofing / Elevation (auth bypass) | serve_webui.go route mount | mitigate | `/api/graph/schema` + `/api/graph/query` mount as SPECIFIC siblings under the `/api/` carve-out behind the Phase-24 `RequireAuth` whole-origin gate; NO bare `/api/` (would shadow /api/integrations/); read-only → no RequireCapability; a 401-unauth httptest asserts the gate (V2) |
| T-27-01 | Tampering / Elevation (Cypher injection) | handleGraphQuery input | mitigate | Structured-intent-only payload (no raw Cypher field); server-side V5 validation: op enum, length-capped ids, labels/rel-types validated against the live schema set, caps rejected if negative; compilation + parameterization happen in the plan-01 normalizer |
| T-27-05 | DoS / Info Disclosure | handleGraphQuery body + errors | mitigate | `http.MaxBytesReader(maxRunBodyBytes)` bounds the body (Pattern from conversations_api.go); hard node/edge caps bound the result (plan 01); every wire error passes `sanitizeErr`/`SanitizeString` — no raw Cypher/DSN/host leak (V13, HARDEN-08) |
