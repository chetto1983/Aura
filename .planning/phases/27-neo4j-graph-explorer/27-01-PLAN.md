<objective>
Build the read-only graph normalizer: the structured-intent → parameterized read-Cypher compiler, the write-verb guard, and the row-map → `{nodes,edges,paths,schema,query}` contract — the load-bearing backend half of GRAPH-01 and GRAPH-04. This is the contract the REST layer (plan 02) and the frontend (plans 03/04) consume.

Purpose: The cockpit must never author Cypher (D-04/D-05). All injection-safety, the write-verb backstop, and the MCP-serialization quirks (list→NULL, node→property-dict) live server-side here, behind a clean typed JSON contract.
Output: `internal/knowledge/graphview.go` (+ `_intent.go` + `_normalize.go`) + unit tests + the Wave-0 live serialization/footprint integration probe.

Artifacts this phase produces (this plan's slice):
- `GraphView` struct (wraps a `GraphReader`) with methods `Schema(ctx) (GraphSchema, error)` and `Query(ctx, GraphIntent) (GraphResult, error)`
- `GraphReader` interface — `Read(ctx, query string, params map[string]any) ([]map[string]any, error)` (read-only; `*knowledge.Client` satisfies it)
- Flat contract structs: `GraphResult{Nodes []GraphNode; Edges []GraphEdge; Paths []GraphPath; Schema GraphSchema; Query string}`, `GraphNode{ID, Caption string; Labels []string; EntityType string; Degree int; Props map[string]any; RefID string}`, `GraphEdge{ID, Source, Target, RelType string}`, `GraphPath{Steps []GraphEdge}`, `GraphSchema{Labels, RelTypes, PropertyKeys, EntityTypes []string; Counts map[string]int}`
- `GraphIntent` struct: `Op string` ("seed"|"expand"|"schema_overview"), `SeedID, Session string`, `Labels, RelTypes []string`, `NodeCap, EdgeCap int`
- funcs: `compileSeed`, `compileExpand`, `compileSchema`, `assertReadOnly`, `clamp`, `normalizeRows`
- consts: cap defaults/maxes (`defaultNodeCap=75`, `maxNodeCap=300`, `defaultEdgeCap=200`, `maxEdgeCap=800`)
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → GraphView | A structured `GraphIntent` (validated) is the only input; it is compiled to Cypher here, never accepted as raw Cypher |
| GraphView → mcp-neo4j-cypher | Parameterized read-Cypher over `knowledge.Client.Read` (read-tx enforced at the mcp/bolt layer); the param map keeps values structurally separate from the query body |
| Neo4j rows → contract | Untrusted node/edge property strings (agent-memory + documents, partly model/web-derived) cross into the typed JSON contract |

## STRIDE Threat Register (ASVS L1, block on high)

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-01 | Tampering / Elevation | `compile*` in graphview_intent.go | mitigate | Parameter maps ONLY (`$session`/`$labels`/`$node_cap`); a test asserts no bound value appears as a literal in the compiled Cypher; labels/rel-types bound as data in `WHERE x IN $list`, never as Cypher identifiers (D-05, V5) |
| T-27-02 | Tampering | `GraphView.Query` dispatch | mitigate | `assertReadOnly` write-verb guard (CREATE/MERGE/SET/DELETE/REMOVE/DROP/FOREACH + CALL{…write}) runs before every `Read`; the `GraphReader` seam exposes Read ONLY (no Write surfaced); read-tx ALSO enforced at the mcp/bolt layer (defense in depth, V4) |
| T-27-04 | Tampering / untrusted output | `normalizeRows` | mitigate | Node/edge property strings carried as data in `Props map[string]any` and rendered as text downstream (HARDEN-08); the backend never builds HTML; the contract is JSON only |
| T-27-05 | Info Disclosure | error returns from Query/Schema | mitigate | Compile/guard rejects return a sanitized error that never echoes the offending Cypher or DSN; the knowledge client already redacts the Neo4j password (client.go redactSecrets) |
</threat_model>
