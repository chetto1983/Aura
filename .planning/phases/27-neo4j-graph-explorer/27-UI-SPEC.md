# Phase 27 — UI Design Contract

> Visual and interaction contract for the read-only Neo4j evidence-graph workspace (Frame-06 three-pane mode-swap). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> **Pre-populated from** `27-CONTEXT.md` (D-01..D-11), `27-RESEARCH.md`, the locked design system (`web/tokens/tokens.json` → `web/src/styles/theme.css`), the orchestrator LOCKED constraints, and the `accessibility` skill. **Zero operator questions** — CONTEXT.md is exhaustive; the design system is already locked from Phase 23.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (manual design system — no shadcn; not React-component-registry based) |
| Preset | not applicable |
| Component library | Radix primitives only where already adopted (e.g. `@radix-ui` hovercard from Phase 26); the graph workspace is hand-built panels + the Sigma WebGL canvas. No new component-registry blocks. |
| Renderer (graph) | `sigma@3.0.3` + `graphology@0.26.0` + `@react-sigma/core@5.0.6` + `graphology-layout-forceatlas2@0.10.1` (optional `graphology-communities-louvain@2.0.2`), all MIT, lazy-loaded as its OWN Vite chunk (D-01). **NOT** `@neo4j-nvl`/`@neo4j-ndl` (proprietary, theme-clash) and **NOT** three.js/react-force-graph (heavy/3D-decorative). |

## Spacing Scale

The locked token system uses `--space-unit: 4px` (operator density). All graph-workspace spacing is multiples of 4, mapped onto the project's existing scale:

| Token | Value | Usage in the Graph Explorer |
|-------|-------|------------------------------|
| xs | 4px | Legend-chip gap; inline icon-to-label gap; path-strip step inner padding |
| sm | 8px | Filter-toggle row gap; inspector property-row vertical rhythm; node-list item padding |
| md | 16px | Default panel inner padding (left seed/filter panel, right inspector); gap between filter groups |
| lg | 24px | Section breaks inside a panel (seed vs filters vs Cypher-preview); inspector header-to-body |
| xl | 32px | Empty-state / schema-overview block padding; loading-fallback centering inset |
| 2xl | 48px | Major empty-state vertical centering (no-footprint fallback) |
| 3xl | 64px | (reserved — not expected at this surface's panel scale) |

Exceptions:
- **Touch targets — 44px minimum** for every interactive control reachable on mobile (filter toggles, node-list items, inspector action buttons, path-strip steps). This is the D-03 "tap/focus is a first-class access path" requirement, not a decorative size. Allowed override of the 4-multiple cadence is the 44px min-height; padding inside stays on the 4-grid.
- The Sigma **canvas** itself is fluid (fills the center column); it carries no internal spacing token — its layout is driven by ForceAtlas2, not the spacing scale.

## Typography

Exactly 4 sizes, exactly 2 weights. Body base is the operator-density `--font-base: 15.5px`; the scale below is expressed in px for the checker but ships as `rem`/`var(--font-base)`-relative values.

| Role | Size | Weight | Line Height | Font | Used for |
|------|------|--------|-------------|------|----------|
| Display | 22px | 600 (semibold) | 1.2 | Fraunces (`--font-display`) | The workspace title ("Graph Explorer") + the empty-state / schema-overview heading |
| Heading | 18px | 600 (semibold) | 1.25 | Atkinson Hyperlegible Next | Panel headers ("Seed", "Filters", "Inspector"), inspector node-caption, path-strip section label |
| Body | 15.5px | 400 (regular) | 1.5 | Atkinson Hyperlegible Next | Inspector property values, node/edge list items, filter labels, empty/error body copy |
| Label | 13px | 600 (semibold) | 1.4 | Atkinson Hyperlegible Next | Legend chips, filter-group captions, degree/count badges, path-strip rel-type pills, the "Cypher" affordance label |

Monospace exception: the **read-only Cypher preview**, **element-ids**, and raw **property values** render in Commit Mono (`--font-mono`) at the Body size (15.5px) / Label size (13px) respectively — this is a font-family swap on the same size tokens, not a 5th size.

Weights: only **400 (regular)** and **600 (semibold)** — matches the Phase-23 surface discipline. No 500/700.

## Color

The graph workspace is theme-token-driven. Dominant/secondary/accent map to the locked dark-operator BLUE palette (`tokens.json` `dark` set — the operator-accepted default; light mode mirrors via the same token names). **Do NOT re-skin to graphite or any other palette.**

| Role | Token (dark) | Value | Usage |
|------|--------------|-------|-------|
| Dominant (60%) | `--color-bg` | `#131314` | Workspace background; the Sigma canvas background (so nodes read against near-black) |
| Secondary (30%) | `--color-surface` / `--color-surface-2` | `#1E1F20` / `#333537` | Left seed/filter panel, right inspector, path strip, legend, node/edge a11y list — the three-pane "chrome". Borders use `--color-border` `#3C4043`. |
| Accent (10%) | `--color-accent` + `--color-accent-text` + `--color-ring` | `#1F3760` / `#D3E3FD` / `#8AB4F8` | See reserved-for list below |
| Destructive | `--color-danger` | `#F28B82` (dark) | Error-state text/icon ONLY. **There are no destructive *actions* in this read-only phase** — danger is used solely to color the error-state card (query failure / schema-load failure). |

Accent reserved for (explicit — never "all interactive elements"):
1. The **selected/pinned node + its highlighted evidence path** on the canvas and mirrored in the path strip (the single most important signal — D-10).
2. The **active filter toggles** (selected label/edge-type chips) and the **focused node** in the keyboard-traversal a11y list (`--color-ring` focus halo via `--shadow-focus`).
3. The **primary CTA** ("Explore this conversation" / "Expand neighbors") button fill.
4. The **"Show Cypher" affordance** in its active/expanded state.

Everything else (panel chrome, idle filter rows, inspector property labels, idle node fills) uses surface/border/text tokens — accent must stay scarce so the highlighted path is unmistakable.

### Label-family palette (schema-driven — D-02, this phase's distinctive visual system)

The node fill color is a **semantic palette DERIVED from the brand tokens**, mapped from the live `GET /api/graph/schema` label/`Entity.type` set — NOT hard-coded per label, and NOT a rainbow. Known Frame-06 families map to a curated blue-anchored ramp; unmapped labels get a deterministic stable color (hash → the same ramp) so the legend is reproducible across sessions.

| Family (matched from live schema) | Encoding intent | Color basis | Contrast rule |
|-----------------------------------|-----------------|-------------|---------------|
| source / `:Document` / `:Source` / `:Chunk` | evidence origin | brand accent blue `--color-info` `#AECBFA` family | each fill ≥ 3:1 vs `--color-bg` (UI-graphics threshold) |
| entity / `:Entity` (POLE+O via `Entity.type`) | the subjects | a desaturated teal/cyan step off the accent ramp; **`Entity.type` (PERSON/ORG/LOCATION/EVENT/OBJECT) is a SECOND color dimension** (lightness/hue step), not a separate label | ≥ 3:1 vs bg |
| claim / fact / `:Fact` / `:Preference` | assertions | a warm-neutral step (kept distinct from the blue evidence anchor) | ≥ 3:1 vs bg |
| agent / `:ReasoningTrace` / episode | Aura's own memory | `--color-success` `#81C995` family (the "self" signal) | ≥ 3:1 vs bg |
| topic | clustering | a muted violet-grey step | ≥ 3:1 vs bg |
| conflict | contradiction marker | `--color-danger`/`--color-warning` family (reserved — the ONLY warm-alert use on a node) | ≥ 3:1 vs bg |
| (unmapped live label) | deterministic | `hash(label) → ramp index` over the SAME curated ramp | ≥ 3:1 vs bg |

**Color is never the only encoding** (WCAG 1.4.1 + D-03): every node also carries its **label text** (caption) and the legend names each family; the path strip names each step textually. Node **size** encodes degree/confidence (a second, non-color channel). Edge color is a dimmed `--color-border-strong`; the highlighted path overrides to accent.

Contrast gates (hard — D-03, from the `accessibility` skill): node/edge **label text** and legend chip text meet **4.5:1** (normal) vs their backplate; node fills, edge strokes, focus rings, and the highlighted-path stroke meet **3:1** (UI graphics) vs `--color-bg`. The locked tokens already pass the cockpit's `web/scripts/contrast-check.mjs` 15/15; the label-family ramp MUST be added to that check.

## Interaction & State Contract (phase-specific — consumed by planner/executor/auditor)

> The standard template covers tokens; this section pins the interaction contracts the checker/auditor compare against. Every row is a testable visual/interaction obligation.

### Layout — Frame-06 three-pane (D-11)
- When `surface === 'graph'`, the `AppShell` center `<section>` swaps `ExternalStoreChat` → a lazy `<Suspense>`-wrapped `GraphExplorer`. It is a **mode-swap workspace, NOT a dockable window** (no `ui_control` dock/tile/icon-rail).
- Three CSS-grid columns: **LEFT** seed + filters + read-only Cypher preview | **CENTER** Sigma WebGL canvas | **RIGHT** node inspector. A **path strip** spans below the canvas (readable, keyboard/tap reachable).
- Panels use the existing AppShell grid pattern (no new resize-panel dependency required); on mobile the three panes stack / the inspector becomes a focus-trapped sheet (reuse the Phase-25/26 drawer pattern), with the canvas and the a11y node/edge list both reachable.

### Access-path contract (D-03 — HARD a11y gate)
| Obligation | Required behavior |
|------------|-------------------|
| Hover is never the only path | Click/tap a canvas node OR a node-list item opens the inspector. Keyboard: `Tab` into the canvas region, then `Enter`/`Space` opens the focused node's inspector. |
| Keyboard node traversal | A focusable, ordered DOM **node list** (`role="list"`) with arrow-key/`Tab` navigation; `Enter` selects = same effect as canvas click. Focused node mirrors to the canvas via `setNodeAttribute` + `sigma.refresh()`. |
| Screen-reader surface | Node list + edge list as semantic DOM (each item names label / type / degree / neighbor count); the path strip is an ordered list of `node —REL→ node` steps. This DOM mirror is the **non-WebGL fallback** AND the SR surface. |
| Canvas accessible name | `SigmaContainer` wrapper gets `role="img"` + `aria-label` (`graph.a11y.canvasName`). |
| Focus management | Opening the inspector moves focus into it; closing returns focus to the originating node-list item (dialog focus-return). |
| Reduced motion | `prefers-reduced-motion` → skip/shorten the ForceAtlas2 animated settle + camera animation. |
| `aria-invalid` discipline | Any filter/seed input omits `aria-invalid` when valid (`cond \|\| undefined`) — project a11y memory rule. |

### Canvas + visual encoding (D-02, D-10)
- Node **fill** = label-family color (schema-driven palette above). Node **size** = degree (or confidence where present) — a non-color channel. Node **caption** = `name`/`canonical_name`.
- Edge **label** = relationship type (rendered above a threshold zoom). Idle edge = dimmed border-strong; highlighted-path edge = accent.
- Selected/pinned path = accent highlight on canvas AND mirrored in the path strip (D-10). Non-path nodes/edges dim (reducer-driven) so the evidence path reads cleanly — "evidence paths, not hairballs".
- Dense-graph default (D-08): node cap 75 (hard max 300), edge cap 200 (hard max 800); on overflow show `graph.cap.notice`; operator grows the view via **Expand neighbors** (D-04). No hairball dump.

### States (every surface must specify all four)
| State | What renders |
|-------|--------------|
| Loading | Centered skeleton/spinner + `graph.loading`; reuse the cockpit `skeleton.css` shimmer, respect reduced-motion. |
| Empty / no-footprint | Schema-overview (label/rel-type map from `GET /api/graph/schema`) + `graph.empty.*` + the seed CTA. Never a blank canvas (D-07/D-08). |
| Populated | Three-pane with seeded subgraph, legend, path strip, inspector. |
| Error | `--color-danger` card + `graph.error.*` + Retry; never leaks raw Cypher/DSN (sanitized server-side). |

### Read-only transparency (D-04, D-09)
- "Show Cypher" reveals the compiled, parameterized query in Commit Mono with `graph.cypher.note` — it is **display-only, never an editable input**. No raw-Cypher authoring field exists anywhere in this surface.
- Inspector actions are the read-only set: **pin path** (client-side highlight), **open source** (deep-link the Phase-26 `SourceExplorerSheet` via `openSources()` for `:Document`/`:Source`/citation-matched URL), **show Cypher**. **`add note` is NOT rendered** (write → Phase 29).

### Quality seam (frontend gates)
- Split logic from rendering so Vitest ≥85% + Stryker ≥70% is reachable in jsdom (no real WebGL): pure `graphIntent.ts` (filter/color/intent), normalization, and the label-family color mapper are unit-tested; `SigmaCanvas` is mocked in unit and exercised only in Playwright (`graph.spec.ts` + `graph-a11y.spec.ts` with axe + keyboard). The label-family ramp is added to `web/scripts/contrast-check.mjs`.
