## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI flag `--since` → metrics query | Untrusted operator-supplied duration string crosses into the cache_metrics read. |
| fixtures (JSON on disk) → audit replay | Fixture content drives the deterministic replay; a corrupt fixture must fail cleanly (exit 2), not silently pass. |
| audit replay → invariant assertion | The audit is the runtime proof that messages[0] is not poisoned (T-06-01). |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-02 | Tampering | `cache-stats --since` parsing | mitigate | `time.ParseDuration` validates the flag and rejects unparseable input (exit 64) BEFORE any query; the underlying query is sqlc-parameterized (06-03). Never interpolate the arg. |
| T-06-01 | Tampering | `cache-audit` 20-turn replay | mitigate | Runtime-faithful replay reads `Requests[n].Messages[0]` (cloned snapshot, D-05) and asserts the PrefixHash invariant on the REAL `runner.Turn` loop — the headline mitigation; a synthetic Build() hash is forbidden (D-04). SC#5 negative test proves the gate is not silently green. |
| T-06-03 | Information Disclosure | cache-stats output | mitigate | cache-stats prints token counts + cost + hit-rate only — no message content, no API key. `llm.Config` never logged (D-28). |
| T-06-04 | Elevation | — | n/a | Role separation enforced in 06-03's migration; cache-stats reads via aura_app SELECT. |
