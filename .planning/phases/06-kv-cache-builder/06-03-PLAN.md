| migration role (aura_app vs aura_migrate) | DDL privilege boundary; aura_app must not be able to create/alter/drop or mutate metric rows. |
| llm.Usage → persisted metrics | Token counts + cost cross into Postgres; must carry NO message content / no API key. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-03 | Information Disclosure | cache_metrics columns | mitigate | Table stores token counts + cost_usd only — no message content, no API key (D-02a: data is `llm.Usage` numerics). `llm.Config` never logged (D-28). |
| T-06-04 | Elevation | 0007 migration grants | mitigate | `aura_app` gets SELECT, INSERT only (append-only — no UPDATE/DELETE/DDL); ALL only to `aura_migrate`; DDL gated by `AURA_DB_MIGRATE_URL` (amendment #17). Mirrors 0005. |
| T-06-01 | Tampering | — | n/a | Prefix-poisoning surface is in 06-02 (builder) + 06-05 (gate). |
