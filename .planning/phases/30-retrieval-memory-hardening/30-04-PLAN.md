Expose GraphRAG connected-nodes retrieval over the :NEXT_CHUNK/:HAS_CHUNK graph with explicit
per-stage timing, so retrieval returns connected evidence within a documented p95 budget.

of ms) and that rerank is the dominant bounded cost. RET-03 added the :NEXT_CHUNK edges; this plan
builds the GraphRAG path that traverses them and instruments each stage so the budget is provable
(and so RET-05's perf gate has the numbers to assert).

Output: a documents.Service.GraphRAG path that seeds via the vector index, reranks the seed
chunks, 1-hop expands the winners, and records per-stage latency; plus a live tier asserting the budget.
</objective>
