# Phase 21 Plan 01: HookManager + Command Hooks

## Goal

Implement the EXT-1 hook slice: an optional `HookManager` on `LlmAgent`, five fixed insertion points, first-non-nil-wins semantics, in-process hook authoring, and a trust-gated command-program hook runner.

EXT-2 manifest/installer and EXT-3 self-install remain outside this phase.

## Tasks

1. Add the public hook contract:
   - `Hook`, `HookManager`, `HookTurn`
   - `ModelHookResult`, `ToolHookResult`, `ToolResultHookResult`
   - `LlmAgentConfig.HookManager`

2. Wire the five insertion points:
   - `OnTurnStart`
   - `BeforeModel`
   - `BeforeTool`
   - `AfterTool`
   - `OnTurnEnd`

3. Preserve governance and audit:
   - budget remains before `BeforeModel`
   - `BeforeTool` rewrites run before dedup, execution, and `ToolInvocationStart`
   - `AfterTool` rewrites land before RoleTool history append
   - zero-hook path stays no-op

4. Add command-program hook runner:
   - stdin JSON event envelope
   - stdout JSON decision
   - allow/deny/rewrite decisions
   - executable SHA-256 trust gate checked before every event
   - bounded timeout

5. Verify:
   - focused hook tests
   - full `internal/agent` package
   - full `internal/agent/...` subtree
   - cache invariant audit

## Verification Commands

```powershell
go test ./internal/agent -run 'TestLlmAgentHooks|TestHookManager|TestCommandHook' -count=1
go test ./internal/agent -count=1
go test ./internal/agent/... -count=1
bash scripts/cache_invariant_audit.sh
```

## Done Criteria

- Nil `HookManager` does not change ordinary loop behavior.
- In-process hooks can short-circuit model calls, rewrite/veto tool calls, and rewrite tool results.
- First non-nil result wins for result-producing hook points.
- Command hooks can rewrite/deny and fail closed on hash mismatch or timeout.
- Tool invocation events reflect rewritten arguments.
- Cache-stable `messages[0]` remains byte-identical.
