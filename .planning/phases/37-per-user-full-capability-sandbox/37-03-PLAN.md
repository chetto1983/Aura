<objective>
Ship the idle-suspend reaper scaffold as a scheduler TaskKind — NOT a new goroutine (D-08,
goleak discipline). This is an exact-template copy of the Phase-36 `identity_purge` handler +
its 0033 kind-widen migration: a `sandbox_reap` kind, an `SandboxReapHandler` driving a
consumer-declared `SandboxReaper{SuspendIdle}` seam (so `handlers` never imports the sandbox
package), and migration 0034 widening `scheduler_tasks.kind`. The live SuspendIdle impl that
satisfies the seam is wired in plan 37-05; here the handler + kind + migration ship and are
unit/db-proven in isolation.

Purpose: land the schema + handler foundation early (parallel, no code dependency on the box
runtime) so plan 37-05 only has to provide the impl and register it.
Output: `internal/cron/handlers/sandbox_reap.go` (+test), migration 0034 up/down (+reversibility test).
</objective>
