<objective>
Close the Phase-37 BLOCKER (SC#4 / SBX-04): the entire egress-sidecar mechanism
(`egress.go` filter-table floor DROPping RFC1918 + 169.254.169.254 metadata + the shared-services
bridge, the runc-only FQDN allowlist, `ErrRunscFQDNMutualExclusion`) is built, unit-tested, and
correctly launched by `DockerBackend.Resolve/Suspend/Resume/Stop` — **but it is inert in the
shipped binary** because `launchEgress` is a no-op whenever `b.egressImage == ""`, and the ONLY
production constructor (`cmd/aura/serve_dispatch.go:buildSandboxRouter`) builds the backend with
`WithMaterializeSources` only and NEVER calls `WithEgress`. `config.SandboxConfig` has no field to
source an egress image, and zero Go code reads `AURA_SANDBOX_EGRESS_IMAGE` (compose.yaml sets it
as an unconsumed container env). Net today: every per-identity box the binary creates under
`single_user_hardened`/`server_production` has NO network containment — it can reach RFC1918,
cloud-metadata, and the shared Docker bridge.

This is a composition-root WIRING gap, not a sanctioned deferred-live-test. The fix is surgical:
add an `AURA_SANDBOX_EGRESS_IMAGE` config knob (env-catalog triplet, verbatim shape of the
existing `AURA_SANDBOX_IMAGE`), call `WithEgress(cfg.Sandbox.EgressImage)` in `buildSandboxRouter`,
regression-guard the wiring with a docker-free `cmd/aura` unit test, add the composition-root live
DROP re-test (docker_integration, WSL/CI), and truth-up the compose.yaml + ADR docs that currently
overstate the shipped state.

**Locked decision — the default MUST be NON-EMPTY (`aura-egress:latest`).** ROADMAP Success
Criterion #4 requires the floor ON BY DEFAULT under strict profiles ("the default egress posture
is full public internet minus the tenancy boundary … not `--network none`"). A default of `""`
would wire `WithEgress` yet leave the floor OFF unless an operator opts in — which does NOT close
SC#4. A non-empty default also makes box creation fail-CLOSED when the egress image is absent
(correct posture, consistent with the phase's D-09 fail-closed router). Operational consequence
(intended): a strict-profile host MUST have the `aura-egress` image built/available or box
creation refuses — `docker/aura-egress/Dockerfile` already exists from 37-06.

Purpose: makes SC#4/SBX-04 true in the shipped binary — "the host is never exposed" via a live,
enforced containment boundary. Output: a config knob + one `WithEgress` call + a read-only
accessor + two `cmd/aura` tests (docker-free wiring guard + composition-root live DROP) + doc
corrections. No new subsystem.
</objective>
