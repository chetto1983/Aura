<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| aura daemon → dockerd | the daemon holds the Docker client and creates per-identity boxes/volumes |
| box A volume ↔ box B volume | storage isolation must hold at the kernel/volume layer |
| host env → box exec env | secrets must not cross into the untrusted box |

## STRIDE Threat Register (ASVS L1, block: high)

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-04-CROSSVOL | Information Disclosure | shared-volume cross-identity read | mitigate | Named volume `aura-box-<id>` per identity (storage-enforced); TestVolume_CrossIdentityDeny proves cross-deny; never app-prefix scoping. |
| T-37-04-SECRETENV | Information Disclosure | host secret exfil via box env | mitigate | Scrub the box exec env with secret.IsSecretEnvVar (reuse mergeEnv); TestExec_ScrubsSecretEnv. |
| T-37-04-STARVE | Denial of Service | co-tenant resource exhaustion | mitigate | cgroup v2 caps (NanoCPUs/Memory/PidsLimit via toHostConfig, 2CPU/2GB/512pids start) — proven bounded spike 059; tuned by the D-14 benchmark (37-08). |
| T-37-04-RM | Tampering | `--rm` destroys a suspendable box | mitigate | AutoRemove:false pinned in toHostConfig; Suspend=stop-retain (Pitfall 5). |
| T-37-04-CPMSYS | Tampering | shelled docker cp path mangling / symlink escape | mitigate | Go SDK tar streams only (Pitfall 6); materialize strips/rejects symlinks (sandbox-runtime.md). |
</threat_model>
