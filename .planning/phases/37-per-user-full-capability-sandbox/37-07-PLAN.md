<objective>
Route the four non-background host tools into the per-identity box under strict profiles:
`shell_exec`, `fs_read`, `fs_write`, and skill-snippet execution (`skill` `action=use`), plus make
`send_file` box-aware for artifact retrieval. Each of shell_exec/fs_read/fs_write gains a
`Router *usersandbox.SandboxRouter` field (nil = host-direct, today's behavior preserved); the
routed branch calls `Route(ctx)` and, when routed, executes via `backend.Exec` /
`CopyToContainer` / `CopyFromContainer` instead of the host primitive — using POSIX `/bin/sh -c`
(never `windowsShell()`/`pwd -W`, Pitfall 6) and skipping/re-targeting the host-only pre-checks
(AG-018 cwd `os.Stat`, `statSizeWithinCap`, `deniedSkillsWrite`) that would falsely fail a
`/workspace/...` box path against the host fs. The `skill` tool gets a distinctly-named
`SandboxRouter` field (W6) and, under strict, renders its snippet `action=use` frame with the
in-box `SandboxPath` (extended `skillLoader.Snippet` + adapter sourcing from
`skills.SnippetSandboxPath`) so the subsequent *routed* `shell_exec` runs the materialized
snippet inside the box — `action=use` itself executes nothing. `send_file` gains a routed branch
that `CopyArtifactsOut`s a box artifact to a host-readable staging path before delivery (D-10).
On a routed-but-box-failed call every tool returns a deny-shaped `ToolResult` mirroring
`shellApprovalRequiredResult`, NEVER a host fallback (D-09). `web_fetch`/`web_search` are
deliberately NOT routed (D-11). Wire the router onto these tools at the composition root
(`cmd/aura/main.go`).

Purpose: this is SBX-01's core — under `server_production` the real host filesystem is
unreachable because the shell/fs tools operate inside the box, artifacts written in the box are
still deliverable (send_file), and stored snippets run inside the box via the corrected
host-vs-sandbox path selection. The fail-CLOSED shape is the GATE-01 containment invariant made
concrete at the tool layer.
Output: the four routed tools + box-aware send_file + the corrected skill-snippet path selection
+ the fail-CLOSED deny result + the main.go wiring + the strict-exec-in-box integration test +
the fail-closed unit test.
</objective>
