<objective>
Build the SBX-02 crux — the type layer that makes host re-exposure **unrepresentable**, not
merely validated. Ship `SandboxSpec` (the only constructible box-config type, deliberately
missing every escape field), the single private `toHostConfig` translator that pins the
dangerous moby `HostConfig` fields to safe constants as literals present nowhere else, and the
`Backend` interface speaking the corrected-by-082 E2B verbs. This is pure unit-testable work
(no Docker) and it fully closes SBX-02.

Purpose: unrepresentability is structural — a forgotten `if privileged` check can be bypassed,
a missing field cannot be set. Interface-first: define the contracts (spec + translator +
Backend seam + the docker_integration skip-helper) that every later plan builds against.
Output: `internal/sandbox/usersandbox/{spec.go, translate.go, backend.go}` + the SBX-02
structural/behavioral tests + the shared docker_integration test skip-helper.
</objective>
