<objective>
Close the phase the only way this milestone allows: a real run against the live stack, driven
by the real agent.

Two identities hold real conversations at the same time against one running `aura serve`, each
doing useful work on its own data, deliberately raced so the collision is real rather than
sequential — and the pair is scored against a written rubric while a machine-checkable half
decides whether the phase actually closes.

Purpose: E2E-01 and E2E-02 are the requirements every other plan in this phase exists to make
reachable. The existing `two_identity_e2e_*` files never spawn an `aura serve` process and
never perform a real Authula login; `scripts/agui_smoke.sh` does both but drives the
bootstrap-seeded `local` identity, which never passes through `EnforceFirstLogin`'s forced
password change and mandatory TOTP enrollment. Nothing in this repository currently drives a
freshly provisioned identity through first login end to end. This plan builds that.

Output: a committed, re-runnable harness; a blocking machine-checked assertion set; a written
≥9.8 rubric that records rather than gates; and the recorded evidence of one scored run.
</objective>
