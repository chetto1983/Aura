<objective>
Turn the two-identity acceptance gate into something a second person can run.

On 2026-09-07 it passed against the live stack in 2.98 seconds — after two undocumented
manual steps: an ad-hoc socat container to reach Garage's Admin API, and a hand-created
disposable database, because the test rightly refuses to migrate the live one. The socat step
is already fixed by commit `a3536af5d`, which publishes :3903 on loopback. The hand-made
database is not, and neither step is written down anywhere a second person would find it.

Purpose: ISO-02a is the requirement that the gate is reproducible, and a gate that takes two
undocumented manual steps is a gate nobody runs. One command, from a clean checkout, in CI
and locally, running one sequence rather than two that drift.

Output: the disposable-Postgres bootstrap extracted into a library both scripts source, a
`make musr-e2e` target that brings up its own stack and tears it down, a CI job that calls
that same target, and a runbook whose Acceptance section names it.
</objective>
