<objective>
Fence conversation sidecar reads, reconcile crash-orphaned sidecars, and lock the spilled-search exclusion — the security core of the phase (ASVS V12 path traversal).

**LOOP-05 / F-005 (D-08):** both `loadTurns` (`store.go:286`) and `loadBranchTurns` (`store_branch.go:87`) do `os.ReadFile(t.ContentSidecarPath)` on the untrusted DB column. Replace with a single shared `readTurnSidecar(convID, seq)` that reconstructs the path from `(runDir, convID, seq)` and reads it through `os.Root` (`os.OpenRoot(s.runDir).ReadFile(path.Join("conversations", convID, fmt.Sprintf("%d.content", seq)))`), neutralizing a poisoned path AND a symlink swapped at the `.content` leaf. Keep `validateID(convID)` before the join; assert `filepath.IsAbs(runDir)` first; a missing spilled sidecar stays a hard error. This is Aura's first `os.Root` use (Go 1.26.4).

**LOOP-09 / F-040 (D-09):** `scanConversationOrphans` only removes WHOLE orphan dirs; a crash between sidecar-write and DB-commit leaves an unreferenced `<seq>.content` inside a LIVE dir forever. Add an age-grace reconcile: for each live conversation dir, list committed spilled seqs via the new `ListSpilledSeqsForConversation` (from 34-01), and remove `<seq>.content` files whose seq is NOT referenced and whose mtime is older than an age-grace cutoff (mirror `tmpTTL = 24h`). Match STRICTLY the `.content` suffix (co-located `<spillID>.result` tool sidecars MUST survive); reuse the existing `Lstat`/symlink guard. Both the boot scan and the interval `Sweeper` inherit it.

**LOOP-10 / F-048 (D-10):** document + assert that a `>cap` spilled turn (content=NULL) is excluded from the locked trigram `SearchConversationTurns`. Add comments on `maybeSpill` + the search SQL + the model note, and an integration test asserting a `>cap` turn spills and does not surface while an inline turn does.

Purpose: close an arbitrary-file-read vector, bound crash-orphan growth, and pin the search boundary. Wave 2 — depends on 34-01's read-only query. Output: the shared fenced reader, the `.content` reconcile, doc+assert, and their tests (fence unit/tmpfs + reconcile & search integration).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DB content_sidecar_path → filesystem read | The stored path string is UNTRUSTED (a poisoned row could point anywhere); reconstruct instead of trusting. |
| filesystem symlink at .content leaf | An attacker who can write into the conversations dir could swap a symlink to redirect a read outside runDir. |
| live conversation dir contents | A crash leaves unreferenced sidecars; a naive sweep could delete live .result tool history. |
