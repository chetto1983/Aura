<objective>
Build the validation core: `(*Config).ValidateProfile(p) []Violation` that aggregates the generic re-parse pass (plan 03) with a small set of pure, table-testable bespoke gates (each mirroring `GuardWebBind` — `config:`-prefixed, naming the offending knob), then refactor `(*Config).Validate()` to delegate to it (fatals → one joined `config:` error). Purpose: This is the config-contract that refuses unsafe production deploys — the security control at the heart of the phase. The gates encode the D-09..D-16 profile rule matrix exactly.
Output: `config_validate.go` (ValidateProfile + gates + profile-aware Validate), extended `config_validate_test.go` (aggregate e2e + per-gate tables), extended `config_rundir_test.go` (PROF-05), and the bootChatEnv warn-diagnostic.
