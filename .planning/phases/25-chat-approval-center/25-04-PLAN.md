## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-14 | Tampering | hard-delete fired without confirmation (accidental data loss) | mitigate | "Delete permanently" gated behind a focus-trapped confirm dialog (D-07); the test asserts `DELETE` never fires before confirm; archive (reversible) is the primary action |
| T-25-15 | Tampering/Injection | XSS via a conversation title or FTS snippet | mitigate | Titles/snippets render as React text nodes (auto-escaped), never `dangerouslySetInnerHTML`; the highlighted-match wrapping uses safe element composition, not raw HTML |
| T-25-16 | Spoofing | unauthenticated read of conversation metadata | mitigate | All `/api/conversations…` reads inherit `RequireAuth` (plan 25-01 mount); the SPA fetches same-origin with credentials |
| T-25-SC | Tampering | npm installs | mitigate | This plan adds NO new dependency (reuses React Query + react-router already in package.json) |
</threat_model>
