| Boundary | Description |
|----------|-------------|
| Browser → /api/approvals/{token}/resolve | Operator verb resumes/cancels a (possibly background) thread's run |
| Pending question text → DOM | Server-projected (sanitized, plan 25-02) question/answer renders in the card + list |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-17 | Tampering | "Decline" silently submits the operator text as an ACCEPTED answer (deny ≠ accept) | mitigate | The card sends `{action:"decline"}` with NO operator content; the server injects `declinedContent`; the test asserts the payload action + the absence of operator content (Pitfall 4 footgun guard) |
| T-25-18 | Information Disclosure | a stale/auto-terminated interrupt silently vanishes (operator loses track of a background HITL) | mitigate | D-06 — terminal state rendered inline AND in the badge list (Task 1 + Task 2), verbs disabled, never omitted |
| T-25-19 | Elevation of Privilege | the resolve mutation resumes another thread's run unauthenticated/uncapable | mitigate | Inherited from plan 25-02: `/api/approvals/{token}/resolve` behind `RequireAuth` + `RequireCapability`; same-origin fetch with credentials; SameSite=Strict cookie (no cross-origin write path — CSRF mitigated) |
| T-25-20 | Tampering/Injection | XSS via the pending question / option text | mitigate | Question/options render as React text nodes (auto-escaped), never `dangerouslySetInnerHTML`; server already `SanitizeString`s the surfaced strings (plan 25-02) |
| T-25-SC | Tampering | npm installs | mitigate | This plan adds NO new dependency (reuses React Query + router) |
</threat_model>
