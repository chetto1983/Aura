### Runtime adapter (Claude's Discretion — RESOLVED)

- **Use `useExternalStoreRuntime`** (assistant-ui) mapping the EXISTING `POST /agent/run` SSE + `GET /threads/{id}/messages` snapshot into assistant-ui's `ThreadMessage[]` model. Rationale: Aura's SSE is a custom AG-UI event shape (text + `REASONING_*` + tool start/args/end), NOT the AI-SDK Data Stream wire format, and D-09 requires **branch/edit/regenerate + stop** — all first-class on the external-store runtime (it exposes `onCancel`, `setMessages`, branching via `getBranches`/`switchToBranch`, and `onEdit`/`onReload`). `@assistant-ui/react-ag-ui` (named in PROJECT.md) is the fallback ONLY if research confirms at plan time that it cleanly carries the branch-tree + stop affordances over `POST /agent/run`; otherwise external-store is the contract.

## Spacing Scale

The shipped system is **density-driven**, not a fixed px ladder: spacing derives from `--space-unit` (operator = 4px, compact = 3px, review = 6px) and `--row-h` (operator = 32px). Tailwind's default 4px-base utilities (`gap-1`=4px, `gap-2`=8px, `px-3`=12px, `px-4`=16px) are the shipped convention (see `AppShell.tsx`). All declared values are multiples of 4 at operator density.

| Token | Value (operator) | Usage |
|-------|------------------|-------|
| unit | `var(--space-unit)` = 4px | Base scalar; all rhythm is a multiple of this |
| xs | 4px (`gap-1`, `p-1`) | Icon gaps, badge inner padding, citation-bubble inset |
| sm | 8px (`gap-2`, `p-2`) | Compact element spacing, message-part gaps, footer chip gaps |
| md | 12px (`px-3`, `py-2`) | Default element / composer padding, list-row inset (matches header `px-3 py-2`) |
| lg | 16px (`px-4`, `gap-4`) | Card padding (approval card, message block), section padding (matches `sm:px-4`) |
| xl | 24px (`gap-6`, `py-6`) | Conversation-group separation, drawer padding |
| 2xl | 32px | Empty-state vertical centering block |
| row-h | `var(--row-h)` = 32px | Min interactive row height (list rows, inline controls) |

Exceptions:
- **Touch targets**: primary CTA min-height **44px** and icon-only buttons **min-w-11 / min-h-11 (44px)** — the shipped LoginPage precedent and WCAG 2.5.8 comfortable target. The 24×24 AA floor is the hard minimum for inline secondary controls; 44 is the standard.
- `0.6875rem` (11px) micro-labels use `text-[0.6875rem]` (shipped uppercase section-label precedent) — for footer metric captions and badge counts only.

## Typography

The shipped scale is small-and-dense (operator `--font-base` = 13px). Reuse the shipped Tailwind size utilities; declare exactly the roles below. **Two weights only**: `font-normal` (400) and `font-medium` (500) — `font-medium` is the heaviest weight in the shipped system (`AppShell`/`LoginPage` use `font-medium`, never bold). Do not introduce `font-semibold`/`font-bold`.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 (`font-normal`) | 1.5 (`leading-relaxed`) | Chat message text, approval question, list titles |
| Label | 12px (`text-xs`) | 500 (`font-medium`) | 1.4 (`leading-snug`) | Mode-switch items, tool-call names, button labels, badges |
| Heading | 20px (`text-xl`) | 500 (`font-medium`) | 1.2 (`leading-tight`) | Empty-state heading, panel titles (matches LoginPage `text-xl font-medium`) |
| Micro | 11px (`text-[0.6875rem]`) | 500 (`font-medium`) | 1.3 | Footer metric captions, badge count, "compacted N turns" marker, uppercase section labels (`uppercase tracking-wider`) |
| Mono | 12px (`text-xs font-mono`) | 400 | 1.5 | Raw tool-result blob, token counts, `$0.0042`, cache `83%`, JSON dump |

> **Aesthetic note (CLAUDE.md `<frontend_aesthetics>` vs. shipped token).** The shipped body face is `Inter`, which the project aesthetic directive flags as a generic default. This phase **keeps `Inter`** because the font is a LOCKED Phase-23 token and changing it would fork the design system mid-milestone (the directive equally says: extend, stay cohesive, the brief's locked decisions win). The distinctiveness budget for Phase 25 is spent instead on (a) the **mono face carrying all numeric/runtime instruments** — a deliberate instrument-panel signature, not decoration — and (b) the **disciplined two-weight, small-dense operator scale** that reads as a control-room console, not a consumer chatbot. If a display-face swap is ever desired, it is a separate `tokens.json` change with its own design pass, never an inline Phase-25 override.

## Color

The shipped dark-operator palette is the contract. The 60/30/10 split maps directly onto the shipped tokens.

| Role | Token / Value | Usage |
|------|---------------|-------|
| Dominant (60%) | `--color-bg` `#0B0E14` (`bg-bg`) | App background, chat stream region, composer well |
| Secondary (30%) | `--color-surface` `#121620` (`bg-surface`) + `--color-surface-2` `#1A1F2B` (`bg-surface-2`) | Conversation sidebar, approval/message cards, footer bar, drawers, raised inputs |
| Accent (10%) | `--color-accent` `#5BA8FF` (`bg-accent` / `text-accent`) | RESERVED — see list below |
| Destructive | `--color-danger` `#E5484D` (`text-danger` / `border-danger`) | Delete-permanently action + its confirm dialog; "declined/cancelled" terminal state text |
| Success (semantic) | `--color-success` `#3FB37F` | Tool-call "done" status dot, "answered/resumed" terminal chip |
| Warning (semantic) | `--color-warning` `#E0A23C` | "expired / auto-resolved" stale-approval state (D-06), session-expired banner, context-gauge "near-full" fill (≥85%) |
| Borders / dividers | `--color-border` `#2A3140` (`border-border`) | All card/sidebar/footer/drawer separators |
| Text | `--color-text` `#E6E9EF`; muted `--color-text-muted` `#9AA4B2`; faint `--color-text-faint` `#5B6675` | Primary / secondary / tertiary text respectively |

**Accent (`#5BA8FF`) reserved for — explicit list, never "all interactive elements":**
1. The primary send/submit CTA fill (`bg-accent` with text `#0B0E14` on top — the shipped on-accent contrast pattern).
2. `:focus-visible` outline ring on every interactive element (`outline-accent`, shipped pattern).
3. `aria-current` active state on the mode-switch + selected conversation row (`bg-surface-2 text-text` background + an accent left-rule or accent text on the active item only).
4. The cross-thread pending-approval **badge count** (D-04) — accent-filled pill so it reads as the one thing demanding attention.
5. Citation-bubble / "jump to thread" link affordance text.
6. Branch-picker active-branch indicator + the in-flight streaming caret/typing indicator.
7. Context-budget gauge fill below the near-full threshold (switches to `warning` ≥85%).

Everything else (tool-result chrome, list rows, footer chips, reasoning drawer) stays neutral surface/border/text. **Do not** accent-fill secondary buttons, tool cards, or the whole footer — accent must stay scarce to keep its signal.

**Contrast (WCAG AA, hard requirement — the shipped palette already satisfies these, verify on new pairings):**
- Body text `#E6E9EF` on `#0B0E14` and on `#121620` ≥ 7:1 (AAA).
- Muted `#9AA4B2` on `#0B0E14` ≥ 4.5:1 — use muted for ≥14px only; on `surface-2` re-verify.
- Faint `#5B6675` is decorative/large-only — never below 14px on `bg`; for body use `text-muted`.
- Accent `#5BA8FF` as a focus ring on every surface ≥ 3:1 (UI-component contrast).
- Never encode state by color alone (WCAG 1.4.1): pair every status color with an icon + text label (tool dot + name, danger + "Delete permanently", warning + "Expired").

**Destructive actions (each + confirmation approach):**

| Action | Confirmation |
|--------|--------------|
| **Delete conversation permanently** (D-07, `Store.Delete`) | Modal confirm dialog (native `<dialog>` or focus-trapped role="dialog"). Title `Delete conversation?` · body `This permanently deletes "{{title}}" and its messages. ## Interaction & Accessibility Contract

Quality floor (shipped Phase 23 discipline — `eslint-plugin-jsx-a11y` recommended is a blocking lint gate; honor it):

- **Native elements first**: `<button>`, `<a href>`, `<form>`, `<dialog>` over `div role=...`. Tool cards/list rows that act as buttons are real `<button>`s.
- **Keyboard**: every action reachable + operable by keyboard. Composer `Enter` sends, `Shift+Enter` newlines, `Esc` cancels an active run / closes a drawer/dialog. Approval option buttons are tab-ordered; the inline card is focus-reachable when its thread opens.
- **Focus-visible**: `outline-2 outline-offset-2 outline-accent` on every interactive element (shipped pattern). Never `outline: none` without a replacement. Focused elements clear the sticky header/footer (`scroll-margin`).
- **`aria-invalid` omit-when-valid**: `aria-invalid={hasError || undefined}` so React drops the attr when valid (operator-flagged axe finding — `feedback_aria_invalid_omit_when_valid`). Valid tokens only: true|false|grammar|spelling.
- **Live regions**: streaming assistant text in an `aria-live="polite"` region; the running-status row `role="status"`; stream/resume errors `role="alert"`; the cross-thread badge announces count changes politely (not assertively — it must not interrupt).
- **Icon buttons** carry `aria-label`; their SVG is `aria-hidden="true"` (shipped eye-toggle pattern). Status encoded by icon + text, never color alone.
- **Target size**: primary/icon controls 44×44 (`min-h-[44px]` / `min-w-11`); inline secondary controls ≥24×24 (WCAG 2.5.8 AA floor).
- **Dialog**: delete-permanently confirm traps focus, returns focus on close, `Esc` cancels, confirm is not default-focused.
- **Reduced motion**: streaming caret, gauge fill animation, and any reveal respect `@media (prefers-reduced-motion: reduce)` (shipped skeleton precedent disables animation + gradient).
- **Mobile (Frame 05)**: single column; mode-switch stays in header; conversation list + reasoning drawer + approval list open as drawers; composer bottom-pinned; no horizontal overflow. The `AppShell` already collapses the 3-col grid to single-column below `lg`.
- **i18n**: every string via `t()`, present in en+it; no hard-coded user-facing text; rebuild `web/dist` after copy changes.
