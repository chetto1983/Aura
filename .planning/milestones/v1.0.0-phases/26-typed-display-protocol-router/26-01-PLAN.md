<objective>
Build the backend trust boundary for the typed-display protocol (GAP-1): a NEW pure-data Go package `internal/agent/display/` that normalizes structured tool results into a typed `DisplayPayload` union, an additive `Actions.Display` slot on the agent event, and an `aura.display` CUSTOM event branch in the AG-UI translator mirroring the proven `aura.artifact` twin pattern. The package also owns the URL-keyed source registry (D-05) that powers citations + the Source Explorer downstream.

Purpose: Only a trusted Go normalizer may produce a rich-renderable payload (HARDEN-08). This plan establishes that boundary and the wire contract every other Phase-26 plan consumes. It is the foundation wave — no frontend, no I/O, no storage, no migration.

Output: The `internal/agent/display/` package (R2 layout, every file ≤600 LOC), the `Actions.Display` slot, `DisplayEventName` + the `Translate` CUSTOM branch, and an extended golden-events fixture.
</objective>
