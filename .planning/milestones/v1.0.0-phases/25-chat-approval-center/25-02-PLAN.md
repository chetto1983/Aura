<objective>
Close the two backend gaps the approval center needs: (1) `askuser.Store` has no
cross-thread pending read (`ListPending` is per-conversation — D-04/APRV-01), and
(2) the AG-UI `Resume[]` path cannot express "decline" (its `ResumeStatus` enum is
two-state — D-05/APRV-02, Pitfall 4). This plan adds the cross-thread aggregate query
+ store method, and a NEW `/api/approvals/{token}/resolve` adapter that reaches the
Runner's full three-action `SubmitAnswers` directly, plus the cross-thread read route.

Purpose: APRV-01 (cross-thread pending list), APRV-02 (accept/decline/cancel + resume),
APRV-03 (terminal-state rendering) all require these seams. The three-action model
already exists end-to-end in the Runner — the adapter just *reaches* it over HTTP.
Output: `ListAllPendingPausedStates` sqlc query, `ListPendingAll` store method,
`internal/agui/approvals_api.go` (+ tests), and the `/api/approvals` mount.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → /api/approvals | Operator reads cross-thread pending question/answer text |
| Browser → /api/approvals/{token}/resolve | Operator submits a verb that resumes/cancels a (possibly background) thread's run |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-25-07 | Elevation of Privilege | unauthenticated/uncapable caller resumes or cancels another thread's run | mitigate | `/api/approvals/{token}/resolve` behind `RequireAuth` + `RequireCapability(agentRunCapability)` (V4); token `uuid.Parse`-guarded; single-operator owns all threads (no multi-tenant scoping needed — RBAC out of scope this milestone) |
| T-25-08 | Tampering | "Decline" button silently injects the operator text as an accepted answer (deny ≠ accept) | mitigate | Decline maps to `askuser.ActionDecline` → Runner injects `declinedContent`, NOT the operator text; asserted by the decline-content test invariant (Pitfall 4 warning sign) |
| T-25-09 | Information Disclosure | malformed token → 500 leak | mitigate | `uuid.Parse` the token before the store/runner call → clean 404; `ErrPauseNotFound` → 404/409; errors via `sanitizeErr` |
| T-25-10 | Tampering | SQL injection on the new aggregate query | mitigate | Parameterized sqlc only (`LIMIT $1`); the SELECT is the copied LOCKED contract — never interpolate |
| T-25-SC | Tampering | go/npm installs | mitigate | This plan adds NO new dependency (pure wiring over shipped stores + Runner) |
