<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| iterator frame ↔ N concurrent child goroutines | yield must be serial from the frame; channels need exit paths or goroutines leak |
| escalate signal ↔ errgroup | escalate is a control signal, not a failure — must not pollute errgroup.Wait() |
| child budgets ↔ shared atomic counter | every child shares one *atomic.Int32; a fresh budget reintroduces depth³ |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-13 | Denial of Service (slow) | goroutine leak when consumer breaks early / on cancel | mitigate | `defer close(done)` + every channel op a 2-arm select with `case <-done`/`case <-ctx.Done(): return nil` + `defer cancel()` + spawn-loop guard (D-23, Go #61611); proven by `_NoGoroutineLeak_When_ConsumerBreaksEarly` + goleak.VerifyNone |
| T-02-01 | Denial of Service | depth³ budget explosion via fresh-per-child budget | mitigate | `Budget.Child` shares the same `*atomic.Int32` by pointer (D-10); SC#3 test asserts ≤25 across a 9-leaf tree; tool-wrapped-sub test guards Pitfall 3 |
| T-02-14 | Tampering | fake sentinel error for escalate pollutes errgroup.Wait() | mitigate | escalate uses a captured `context.CancelFunc` (D-03), never a fake error; cancelled siblings drain `(nil,nil)` (D-05) so the error slot carries only real failures |
| T-02-15 | Denial of Service | unbounded buffer growth under a slow consumer | mitigate | synchronous ack-channel backpressure (producer waits for ack); proven by `_BackpressureAckChannel` |
</threat_model>
