<objective>
Close the integration gap a LIVE Gate-3 run exposed in Phase 8 / CAP-02: the per-conversation session containers the SessionManager creates and the HTTP exec path the runner drives were never wired together. Execution routes ALL session exec to the SHARED stateless `aura-sandbox` sidecar (`DockerRunner.url`), which is `read_only` with only a tmpfs `/tmp` and no `/workspace` — so workspace persistence (crit 1b), the live host symlink cascade (crit 2), shell sessions, boot lazy-recreate, and the live egress posture (crit 4) do not hold. Meanwhile `sessions.go runArgv` builds a hollow per-conv container with NO `-v` workspace mount and NO published port; it is only a registry row + reaper target.

This plan binds execution to the PER-CONVERSATION container exactly as D-05 / prd.md:1252 already mandate ("l'esecuzione resta HTTP verso la porta del container per-session" — execution stays HTTP toward the per-session container's port), gives each container its own workspace bind-mount + loopback-published sidecar port, fixes the boot lazy-recreate, and starts the egress proxy at boot. It does NOT touch the integration-criteria tests — they correctly encode the ROADMAP CAP-02 criteria; the implementation is what is incomplete.

THE CRITICAL CONSTRAINT (BLOCKER-1 resolution): the live tests build the runner and the manager as TWO INDEPENDENT objects on the do-not-touch list — `runner := integrationRunner(t)` (docker_integration_test.go:45-48, `NewDockerRunner(&config.Config{SandboxURL: sidecarURL(t)})`, no resolver-injection seam) AND `m, _ := liveManager(t, ...)` (sessions_live_integration_test.go:38-58, no resolver field) — then call `m.Acquire(ctx, convID)` then `runner.RunPythonSession(ctx, convID, …)`. Neither helper can be edited. THEREFORE the resolver MUST be a PROCESS-SCOPED SHARED package-level singleton (`var defaultSessionEndpoint = NewSessionEndpoint()`): SessionManager.create registers into it (when SessionDeps.Endpoint is nil), and NewDockerRunner defaults DockerRunner.SessionEndpoint to the SAME package var. Then the independently-built test runner reaches the per-conv container by convID AFTER Acquire registered the endpoint — by construction, with the test files byte-identical. Composition-root-only wiring does NOT work and would regress the currently-passing 1a/1c via ErrSessionEndpointUnknown.

Purpose: make the existing unmodified live tier (sessions_live_integration_test.go, workspace_integration_test.go, network_integration_test.go, sessions_integration_test.go) go green against real per-conv containers, then close CAP-02.
Output: process-scoped shared per-conv-container exec routing + workspace mount (nosuid,nodev,noexec) + shell-capable image + boot lazy-recreate fix + reaper/recovery endpoint teardown + boot-started proxy + live Gate-3 sign-off.
