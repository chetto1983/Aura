<objective>
Add the `aura memory` operator CLI: a verb router that opens the managed memory sidecar over
streamable-HTTP and calls the raw `memory_*` MCP tools directly (bypassing the agent loop),
the same shape as `cmd/aura/mcp_tools.go` / `runMCPCommand`. This plan satisfies D-01
(agent-decides capture — the operator CLI is the deliberate, explicit write surface, no
passive extraction), D-02 (writes only when invoked — preferences via an explicit verb, never
background inference), D-03 (pull-on-demand recall via `memory_search` and the read verbs),
and re-scoped UX-08 (the operator's recall verb is the hook the 15-04 advisory snapshot
measures recall@5/p95 against).

Purpose: Operators (and the 15-04 integration tests) need a direct, loop-free way to seed and
read memory for verification and ops, exactly like `aura mcp tools`. This is the Claude-Code
parity surface: explicit, agent-judged writes; on-demand recall; no ceremony. The exact
verb→tool mapping is Claude's Discretion (D); this plan locks a concrete mapping over the
ground-truth 16-tool surface (spike 032).

Output: `cmd/aura/memory.go` (verb router + direct CallTool), wired into `main.go` +
`usage()`, plus a unit test driving the verb→tool mapping over a fake transport.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator CLI → memory sidecar (MCP) | `aura memory` opens the loopback sidecar and calls tools directly; the returned text is untrusted content printed to the operator. |
| operator args → MCP tool args | CLI args are marshaled into tool-call JSON; a write verb (`add-entity`/`query`) mutates/reads the graph. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-03-01 | Tampering / Elevation | `aura memory query <cypher>` → `graph_query` | mitigate | `graph_query` is read-only Cypher (spike 032 verified); the verb exposes only that read-only tool — no write-Cypher verb is offered, so there is no write-via-Cypher escape from the operator CLI. |
| T-15-03-02 | Info disclosure | Memory contents printed to the operator terminal | accept | Single-user `local` (D-10); the operator owns the data they read back. No secret is printed (the recipe URL carries no credential; the sidecar holds no API key on the wire). |
| T-15-03-03 | DoS | CLI hangs on a dead sidecar | mitigate | Every verb wraps the call in `context.WithTimeout(ctx, 20*time.Second)` (the established `mcp_tools.go` pattern) so a down sidecar fails fast with a clear error, never hangs. |
| T-15-03-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this Go-CLI plan; the sidecar image build is plan 15-05. RESEARCH §Package Legitimacy Audit: zero new Go modules this phase. |
</threat_model>
