## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Telegram user command → backends | /cost,/search read conversation/cost data; /cancel cancels an in-flight turn |
| onboarding deep-link token → account | a single-use credential admits a Telegram user as the `local` identity |
| pause callback → Runner resume | a button/reply resolves a persisted pause; only the Runner may write paused_states |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-06-TokenReplay | Spoofing | onboarding.go /start token | mitigate | ConsumeOnboarding is single-use (consumed_at) + 1h TTL; a replayed/expired token writes no account (Task 3) |
| T-13-06-PauseHijack | Tampering | hitl.go callback | mitigate | resolve only against the pause token the Runner issued; channel never writes paused_states (Runner is sole writer) |
| T-13-06-CmdLLMBypass | Elevation | commands.go | mitigate | the 10 commands intercept BEFORE any LLM dispatch (no agent.Run on a command) — proven by the no-LLM test |
| T-13-06-CaptionInject | Tampering | artifact.go caption | mitigate | ASCII-sanitize the document caption (Pitfall 4) |
</threat_model>
