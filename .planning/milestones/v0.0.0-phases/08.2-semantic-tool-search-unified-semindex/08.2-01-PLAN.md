<objective>
Extract a reusable `internal/semindex` embedding-index core (Req-1, D-01): one shared
*unexported* pure math core (`cosine`/`l2normalize`/`centroid`/`margin`/bank ops over
`[][]float64`, lock-free, no ctx, no I/O) plus two *exported* typed wrappers —
`Classifier` (Centroid mode: argmax over per-group means → best label + top-2 `Margin`)
and `Ranker` (PerItem mode: top-K cosine over individual docs → `[]Scored{Label,Score}`).
Each wrapper holds the `Embedder` seam + one `sync.RWMutex`; both expose vector-in doors
(`AddVecs`/`RankVecs`) alongside text-in (`Add`/`Rank`). `semindex` owns the `Embedder`
interface so `documents.EmbeddingClient` satisfies it with no adapter (Req-1 constraint).

Purpose: This is the foundation both consumers (the tool ranker, the reasoning classifier)
import in later waves. The math is lifted verbatim from `reasoning_classifier.go:218-264`;
the NO-GOD-CLASS split (4 files, each ~140-150 LOC) is exactly why D-01 rejected the
single-`Index`-with-mode-enum shape.
Output: `internal/semindex` package with `-race`-clean unit tests, importable by ≥2 consumers.
</objective>
