# Phase 08.2 Plan 05: Tool-selection active-learning loop Summary

Added the only net-new mechanism in the phase — the self-improvement loop that closes the "model improvised instead of using a dedicated tool" failure mode (the bitcoin miss). A cheap mis-route detector flags a turn when a shell/fs-fallback tool was used OR the used-tool != the free ranker's top-1 (symmetric `sameTool` split on `__`, NOT a suffix match — the spike-057 P0.78->0.88 fix); a two-tier oracle labels the confident cases for free (the ranker's high-margin top-1) and escalates the low-margin tail to the EXISTING DeepSeek router (no new sidecar, Req-8; kill-switched `AURA_TOOLSELECT_ORACLE`); confirmed `(query-embedding -> tool)` exemplars persist to a Neo4j `:ToolSelectionExample` store (mirroring `reasoningstore`, BOTH mandatory Cypher list-param workarounds copied verbatim); and a per-tool centroid (positives-only Rocchio, `semindex.Classifier{Centroid}` keyed by tool) re-ranks `tool_search` as a margin-gated stage-2 boost (`alpha>=beta`, `boost<=eps*desc_cos`, fires only above `tau` + min-support N>=3, strict no-op otherwise). The whole loop rides the shared `internal/activelearn` mechanism (Plan 04 — the SECOND consumer, proving D-05), and the `(request, used-tool)` signal is captured LIVE at the named off-hot-path `runner_persist.go` `persistEvent` / `agent.ToolInvocationEnd` branch (Open-Q #3 RESOLVED — proven by a real-turn wiring test, not just synthetic exemplars). `-race`-clean, lint-0, goleak-clean async; coverage 100% / 93.3% / 86.2% / 92.1% on the four owned packages.

## What Was Built

### Task 1 — toolselectstore Neo4j `:ToolSelectionExample` store + both Cypher workarounds (commit e1133d86)
- `store.go` mirrors `reasoningstore/store.go` exactly with the new label `:ToolSelectionExample {hash, tool, embedding, query, source}`. The narrow `GraphClient` seam (`*knowledge.Client` satisfies it) and the `asFloats` APOC-JSON parser are copied verbatim. BOTH mandatory Cypher list-param workarounds (RESEARCH risk #4) are present: the `apoc.convert.toJson(e.embedding)` READ (mcp-neo4j-cypher returns NULL for list columns) and the `UNWIND $rows AS row MERGE ...` WRITE (a top-level list param is dropped). The MERGE key is `sha256(query)` so re-labeling a query is an idempotent UPSERT (risk #10, documented in a comment). `LoadExamples` returns `[]LabeledVec{Tool, Vec, Query}` for the ranker fold. No SQL migration (Neo4j schemaless; MERGE creates on first write).
- `store_e2e_test.go` (tag `reasoning_live`): a Save->Load round-trip that asserts the embedding is recovered byte-for-byte through BOTH workarounds. `envOrSkip` `t.Fatal`s under `$CI` when the Neo4j/granite env is unset (no-skip-as-green); a W-3 in-file comment notes the `reasoning_live` tag ALSO gates this store's live coverage (not only the reasoning corpus).
- `store_test.go`: a deterministic `fakeGraph` covers the `UNWIND $rows` param shaping, the query-keyed-idempotent hash, the APOC-JSON-string + raw-`[]any` parse paths, the Read-error path, and every `asFloats`/`asString` branch — 100% in CI without Neo4j.

### Task 2 — mis-route detector (symmetric sameTool) + two-tier DeepSeek oracle on activelearn (commit c0ff5e1f)
- `detector.go`: `sameTool(a,b)` splits BOTH names on the last `nsDelimiterStr="__"` and compares the bare segments (a bare-name equality, never a suffix test — risk #3). `isMisroute(request, usedTool, ranker)` = shell/fs-fallback (the embedding-free P0.88/R1.00 heuristic, needs no ranker) OR `used != ranker.top1(request)` (symmetric).
- `oracle.go`: `twoTierOracle.LabelAndSave` (the opaque `activelearn.Oracle` seam) = free tier (the ranker's top-1 when its margin >= `confidentMargin=0.05`) else escalation to the `Teacher` (the existing DeepSeek router) gated by `AURA_TOOLSELECT_ORACLE`. `Saver` + `ExampleLoader` seams (`*toolselectstore.Store` satisfies both). Confirmed label persists `(query, tool, vec)`; any non-commit returns `saved=false` so activelearn deletes the hash and a later turn retries.
- `learner.go`: `Learner` (thin wrapper over `*activelearn.Learner`, mirroring `reasoninglearn.Learner`) with `Observe(request, usedTool)` — detects, embeds the flagged request off the hot path, enqueues. `New` returns nil unless Embedder + Saver are wired.
- `loop_test.go`: spike-057 12-trace fixture (7 mis-routes + 5 efficient) detection recall = 1.0 (>= 0.85, Req-5a) + precision 0.88 (spike floor); `sameTool` both-orders symmetric incl. the `web_search`/`search` non-match (risk #3); kill-switch-off makes NO paid call; a confident free label makes NO paid call; a low-margin case escalates exactly once; the `Observe` path rides activelearn (Refresh fires after the async save); an unflagged turn is a no-op; `New` nil-without-deps. `main_test.go` runs the suite under goleak.

### Task 3 — margin-gated stage-2 boost + anti-amplification guards + LIVE wiring + Observe() capture (commit 4a6c5311)
- `search_learn.go`: `learnedBoost` = a per-tool centroid bank (`semindex.Classifier` keyed by tool) + per-tool support counts. `Fold` rebuilds the bank wholesale from the full confirmed set (so the query-keyed UPSERT is reflected, stale labels never linger). `rerank(stage1, qVec)` adds `min(beta*centroid_cos, eps*desc_cos)` ONLY to candidates with `support>=minSupport(3)` AND `centroid_cos>learnedTau(0.35)`, then stable-re-sorts; below threshold it returns the stage-1 order byte-for-byte. The 4 Req-5c guards: min-support floor, the epsilon boost-cap clamp, seeds-authoritative + content-hash dedup + the wholesale-rebuild bounded bank, and oracle-in-loop. `ToolSearch.RankForLearner` ranks the STAGE-1 description bank (never the learned centroids — guard #4). `EnableLearnedBoost`/`FoldLearned` are the wiring hooks.
- `semindex/classifier.go`: `GroupCosine(label, vec)` scores a query against ONE named group's centroid (lazily memoized) — the stage-2 lever (`RankVecs` gives the argmax; this scores a caller-chosen tool).
- `search.go`: `match` embeds the query ONCE (`embedQuery`, the single Req-6 error surface) and reuses the vector for `ranker.RankVecs` (stage-1) + `guardedTiebreak` (Plan-03) + `ts.learned.rerank` (stage-2). The `select:` path is unchanged.
- `runner/toolselect_learner.go`: `toolSelectTeacher` (the DeepSeek escalation oracle mirroring `reasoningOracle` — `MaxTokens:32`, `Temperature:0`, `ToolChoice:"none"`, `Reasoning.Enabled=false`; validates the reply against the live deferred-tool catalog to reject hallucinations). `buildToolSelectLearner` enables the learned boost over the SAME granite embedder (W-5: reuses the Plan-03 ranker embedder, does NOT re-wire), wires the detector (the tool_search ranker) + the teacher + the `toolselectstore` saver onto activelearn, with `Refresh` re-folding the centroids via the `ExampleLoader` type-assert.
- `runner/runner.go` + `runner_persist.go`: a `toolSelectObserver` interface field; `turnTracker.userMsg` threaded in `turnLocked`; and the LIVE capture — `r.toolSelectLearner.Observe(tr.userMsg, ti.ToolName)` on the `agent.ToolInvocationEnd` branch in `persistToolTurn` (off the hot path, non-blocking, nil-safe, skipped on a resume round). Open-Q #3 RESOLVED.
- `cmd/aura/chat.go`: `ToolSelectSaver` wired over the same Neo4j client as the reasoning store, so the loop is live when reasoning learning is on.
- `search_learn_test.go`: Req-5b (fold confirmed exemplars + refresh raises a held-out tool's rank vs the no-fold baseline); Req-5c guard #1 (a sub-min-support poisoned label is byte-identical no-op, never flips a seed-correct routing); Req-5c guard #2 (the boost cap protects a strong base match even at >= min-support); below-tau no-op; nil-boost passthrough. `runner_toolselect_test.go`: the Open-Q #3 LIVE-wiring proof (a real ToolInvocationEnd turn invokes `Observe(userMsg, toolName)` exactly once via a fake observer), the resume-round no-capture case, and the nil-learner no-op.
