<objective>
Implement D-22 keyless boot (Req 9, D-10): `aura serve` must boot without an `OPENROUTER_API_KEY` so the Phase-13 setup wizard can collect the key later, and an agent call made without a key must fail-CLOSED with a structured `{"error":"llm_not_configured","hint":...}` — never a boot panic. The current `config.Load()` composes `llm.Load()`, which returns `ErrMissingAPIKey` on an empty key (`llm/config.go:208-209`), and `bootChatEnv` (`chat.go:142`) propagates it so the daemon won't start. This mirrors the established empty-`SEARXNG_URL` fail-soft pattern (empty default + `web_search_unavailable{searxng_not_configured}` at call time).

Purpose: in the appliance/installer flow the key is often not set at first boot; the stack must reach healthy and the wizard collects the key. `db migrate`/`LoadDB()` already boot keyless and stay UNCHANGED; the interactive `chat` path keeps its friendly fail-fast UX.
Output: an `llm` load variant tolerating an empty key, a `config.LoadServe()` (or `Load` option), the serve-path composition root booting keyless, and a call-time guard emitting `llm_not_configured`, plus tests mirroring `TestSearxngURL*`.
</objective>
