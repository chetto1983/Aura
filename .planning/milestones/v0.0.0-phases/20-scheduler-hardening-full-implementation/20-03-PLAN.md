The 6-case unit test pins every branch incl. explicit-route-wins (R7) so a misroute is caught pre-merge. |
| T-20-08 | Tampering / double-delivery | owns-but-failed falling back to a sibling route | mitigate | `(false,err)` → insert a `failed` pending row + return handled=true (NO Notifier call) so the same-channel Step-2 retry is the only re-attempt; the unit case asserts Notifier is NOT called.
