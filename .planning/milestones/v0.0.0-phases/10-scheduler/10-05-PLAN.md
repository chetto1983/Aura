## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cron → docker | backup handler shells out to docker exec (high-privilege if misused) |
| cron → MCP egress | Notifier self-sends job output to WhatsApp/mail (exfiltration surface) |
| cron → LlmAgent | agent_job runs a tool-bound model with no human responder |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-15 | Elevation | docker socket exposure via backup exec | mitigate | Fixed-argv `docker exec` (LookPath-gated), NEVER mounts /var/run/docker.sock (Task 2, D-26, Phase-8 precedent) |
| T-10-16 | Tampering | argv injection into backup command | mitigate | argv is operator-config constants, not model output; //nolint:gosec G204 justified; no string interpolation of payload into the command (Task 2) |
| T-10-17 | Information Disclosure | notification exfiltration of run output | mitigate | Delivery only to the per-task route's configured recipient (AURA_SCHEDULER_NOTIFY_RECIPIENT / explicit notify field); MCP allowlists already scope send_message/send_email (Task 2, D-19/D-20) |
| T-10-18 | Destruction | agent_job with a destructive tool payload | mitigate | scoring gating at schedule time (10-04 D-27) + RequiresImmediateAlert rides the Notifier at dispatch (Task 2); agent_job runs minus swarm_spawn (Task 1) |
| T-10-19 | DoS | unbounded agent_job (no human responder, ask_user loops) | mitigate | budget-from-row hard cap (SC#4) + ask_user auto-reject inject-and-continue completes <30s (Task 1, D-24/D-25) |
| T-10-20 | Repudiation | silent-failing cron | mitigate | notify-on-failure (D-21) + audit summary always written + SC#3 24h missed-backup alert (Task 2) |
| T-10-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages in this plan. |
</threat_model>
