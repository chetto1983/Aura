<objective>
Close H8: microcompact's `dropOldestPairs` does `body = body[2:]` per iteration, assuming strict
user/assistant alternation. But `role='tool'` turns are first-class persisted rows (applyL1), so a
real round is `assistant(tool_calls) → tool → tool → assistant`. A 2-stride drop slices mid-round,
leaving an orphan `tool` turn at the head of `body` (a tool result with no preceding assistant
tool_call). `toMessages(reduced)` goes straight to the LLM, which rejects the wire-invalid shape →
the turn 500s instead of compacting. Every existing `context_boundary_test.go` fixture is
user/assistant-only, so the tool case is untested (D-04 false-green class).

Purpose: a long tool-using conversation must compact cleanly, never produce wire-invalid history.

Output: a boundary-aware drop (advance to the next `RoleUser` so a whole round leaves together; skip a
dangling `RoleTool` head after reducing), and a new fixture exercising the tool round (D-04).
</objective>
