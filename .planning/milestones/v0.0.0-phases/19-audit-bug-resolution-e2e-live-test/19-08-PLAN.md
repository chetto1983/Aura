<objective>
Close the remaining scheduler-contract findings (the same `internal/cron` package as 19-07, so this
plan runs AFTER 19-07 to avoid double-touch on shared files): M-g (`ReschedulesOnRecovery` is a dead
safety control — `catchUpMissed` re-fires EVERY overdue task and never consults the flag, so the PRD
recovery invariant "never auto-re-execute committed side-effects when the flag is false" is never
enforced — benign today since only idempotent handlers are false, latent for any future side-effecting
false handler), M-h (a shutdown mid-run calls `CompleteRun(ctx,…)` with the signal-cancelled root ctx,
which pgx rejects and only logs, leaving the run stuck `running` until the 90s orphan window), and L5
(the `FOR UPDATE SKIP LOCKED` on `DueTasks` runs on the autocommit pool so the row lock releases the
instant the SELECT returns — inert defense-in-depth that could mislead a maintainer; correctness is
held by the per-task `pg_try_advisory_lock`).

Purpose: M-g restores the recovery invariant; M-h removes the shutdown-stuck-run window; L5 removes a
misleading inert lock.

Output: the flag consulted in catch-up, a detached terminal write on shutdown, and the inert SKIP
LOCKED dropped/folded.
</objective>
