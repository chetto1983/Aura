# Phase-OUT Live Thrash Regression Bench

**Run date:** 2026-05-23 (post US-OUT-01..09)
**Scenario:** Repeating web_search → 404 → retry loop (first observed 2026-05-22)

## Pre-fix baseline (2026-05-22 production log)

| Metric | Observed |
|--------|----------|
| LLM calls | 28 |
| Tool calls | 33 |
| Elapsed | ~179 668 ms (~3 min) |
| Delivered | false (empty reply) |
| Stop cause | Context cancelled (no guard fired) |

The agent called `web_search` up to 9 times for the same query, retried 4 ignored 404
responses, and eventually exhausted the conversation context without producing a reply.

## Post-fix expected behaviour (Phase-OUT guards stack)

| Guard | Story | Fires when | Effect |
|-------|-------|------------|--------|
| Repeated-lookup throttle | US-OUT-03 | 3rd identical `web_search` query | Returns inline "blocked" error; model must move on |
| Per-class web budget | US-OUT-07 | 4th `web_*` call in a turn | Returns budget-exhausted error inline |
| Wall-clock cap (60 s) | US-OUT-08 | Turn exceeds 60 s | `stop_reason=wall_clock_exceeded` → synthesis |
| Token budget (500 k) | US-OUT-08 | Cumulative tokens > 500 k | `stop_reason=token_budget_exceeded` → synthesis |
| Force-finalize (Hermes) | US-OUT-09 | Any budget signal fires | ONE synthesis LLM call with stop_reason; non-empty reply |

## Post-fix targets

| Metric | Target |
|--------|--------|
| LLM calls | ≤ 8 |
| Tool calls | ≤ 6 |
| Elapsed | ≤ 30 s |
| Reply | NON-empty; contains stop_reason string |

## How to reproduce when Aura is live

```bash
# Mint a token (see reference_aura_token_bootstrap_db_insert.md)
TOKEN="$(cat .planning/qa/token.txt)"

# Send the thrash query via probe_chat
go run ./cmd/probe_chat -token "$TOKEN" \
  -query "cerca informazioni sul bilancio comunale di roma 2023 2024 2025" \
  -min-length 50 \
  -max-llm-calls 8 \
  -max-tool-calls 6 \
  -max-elapsed-ms 30000 \
  -require-keyword "stop_reason"
```

Expected outcome post-Phase-OUT:
- The 3rd identical web_search is blocked by US-OUT-03 repeated-lookup throttle
- The 4th web call is blocked by US-OUT-07 web budget cap (default=3)
- If neither fires in time, US-OUT-08 wall-clock (60 s) or token budget trips
- US-OUT-09 synthesis produces: "Budget exhausted (signal: wall_clock_exceeded).
  Synthesize the best answer you have from the context so far..."
