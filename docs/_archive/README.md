# Archived Documentation

This folder keeps superseded planning, QA, and research documents for
provenance. Active planning state lives in `PRD.md`,
`.planning/post-drift-2026-05-21/INDEX.md`, and the relevant phase folder.

Do not execute archived plans or QA matrices as current instructions. When an
active document needs historical evidence, link to the archived path explicitly.

Archive groups:

- `qa-2026-05-18-19/` - pre-consolidation QA/tool-surface reports.
- `stale-2026-05-24/` - individual superseded plans and surveys.
- `wiki-retrieval-research-2026-05-21/` - old Phase-WIKI-B research bundle.
