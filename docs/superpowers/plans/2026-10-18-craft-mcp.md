**Goal:** the agent edits spreadsheets, PDFs, Word and PowerPoint files, photos and video through six Craft
MCP servers in its box; Aura's own media editors, the `aura-video-mcp` plan and the heavy Office toolchain
leave the repository and the images.

**Architecture:**
- Six built-in box recipes (`internal/mcp/manager/catalog.go`), default-on, launched in the identity's box
  like agent-browser.
- `internal/agent/mcptools` gains two per-recipe tables: the tools to hide (desktop-only) and the action
  class of every other tool; for the Craft sources the table wins over the server's `destructiveHint`.
- The CLIs ship in `docker/aura-sandbox/Dockerfile`, pinned by release tarball SHA-256 per architecture.
- Six embedded skills (`internal/skills/embed/<app>-aura/`).

**Tech Stack:** Go 1.27; the MCP go-sdk; Docker; React 19 cockpit (deletions only).

**Spec:** `docs/superpowers/specs/2026-10-18-craft-mcp-design.md`. **Spike:** `spikes/craft-mcp/FINDINGS.md`.

## Global Constraints

- Every Go change test-first; `go vet`, build, tests and `-race` (WSL) per touched package.
- No file over 600 lines; refactor on touch.
- The tool lists the tests pin are the ones the spike captured from the pinned versions
  (`spikes/craft-mcp/tools/*.json`), copied to `internal/agent/mcptools/testdata/craft/`.
- The web suite, typecheck, lint, dup and knip stay green after each deletion.
- `internal/webui/dist` is rebuilt after the web changes.

## Review Focus

1. A hidden tool must be unreachable: not in the manifest, not in `tool_search`, not callable by name.
2. The table-wins rule must not leak to other sources: calendar, whatsapp, memory and browser keep honouring a
   server's `destructiveHint`.
3. A Craft tool absent from its table must fail closed (unknown), not pass as a read.
4. Nothing in the cockpit, the e2e suites or the Go tree may still import what the deletions remove.

## Decisions taken while writing this plan

- **Tarball digest only.** agent-browser pins its npm tarball and the extracted binary; here the binary comes
  out of a tarball whose SHA-256 GitHub publishes per release asset, so a second hash adds nothing. Cost if
  wrong: none for integrity.
- **Default-on.** The binaries are in every box, as agent-browser is; an install step would be a trap like the
  one `containerDefaultOnRecipes` documents for calendar and whatsapp.
- **No font package.** DeckCraft's "missing fonts" report is informational; it bundles Liberation and Carlito
  (FINDINGS 6).
