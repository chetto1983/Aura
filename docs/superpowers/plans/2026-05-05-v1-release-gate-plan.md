# v1 Release Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove Aura v1.0 is ready to tag by running automated Go, web, sandbox, migration, packaging, and manual Windows production smoke gates.

**Architecture:** Treat this as a gate, not a feature slice. Run deterministic automated checks first, build a local snapshot release artifact with GoReleaser, inspect the packaged runtime contents, then record any manual Windows smoke steps that still require live credentials or operator interaction.

**Tech Stack:** Go, PowerShell, npm/Vite/ESLint, Pyodide runtime bundle, GoReleaser v2, Windows ZIP smoke.

- [x] **Step 2: Inspect Windows archive contents**

Run:

```powershell
$zip = Get-ChildItem dist -Filter 'aura_*_windows_x86_64.zip' | Select-Object -First 1
if (-not $zip) { throw 'missing windows x86_64 zip' }
Add-Type -AssemblyName System.IO.Compression.FileSystem
$archive = [System.IO.Compression.ZipFile]::OpenRead($zip.FullName)
try {
  $names = $archive.Entries | ForEach-Object { $_.FullName }
  foreach ($required in @('aura.exe', 'README.md', 'INSTALL.md', '.env.example', 'mcp.example.json')) {
    if ($names -notcontains $required) { throw "missing $required in $($zip.Name)" }
  }
  if (-not ($names | Where-Object { $_ -like 'runtime/pyodide/*' })) { throw "missing runtime/pyodide files in $($zip.Name)" }
} finally {
  $archive.Dispose()
}
"release archive ok: $($zip.Name)"
```

Expected: prints `release archive ok: <zip name>`.

## Task 5: Manual Windows Production Smoke

- [ ] **Step 1: Run first-run app smoke from the snapshot ZIP**

Manual operator steps:

```powershell
$zip = Get-ChildItem dist -Filter 'aura_*_windows_x86_64.zip' | Select-Object -First 1
$dest = Join-Path $env:TEMP 'aura-v1-smoke'
Remove-Item -LiteralPath $dest -Recurse -Force -ErrorAction SilentlyContinue
Expand-Archive -LiteralPath $zip.FullName -DestinationPath $dest -Force
Set-Location $dest
copy .env.example .env
notepad .env
.\aura.exe
```

Expected: first-run setup starts without missing runtime files or database migration failures.

- [ ] **Step 2: Verify Telegram and dashboard live paths**

Manual checklist:

- Telegram `/start` reaches Aura and respects the allowlist/bootstrap flow.
- `/login` or the `request_dashboard_token` tool issues a dashboard token.
- Dashboard login accepts the token and can load health, wiki, sources, tasks, settings, skills, and MCP panels.
- A sample PDF upload through Telegram stores a source, OCRs it when configured, and produces or updates a wiki page.
- A reminder scheduled through Telegram fires at the expected time.
- `execute_code` returns at least one CSV and one PNG artifact and sends them back over Telegram.
- The Windows tray "Open Dashboard" action opens the dashboard in the browser.
