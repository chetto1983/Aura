# Work board UI implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement
> this plan inline. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the existing board the space, readable cards and sidebar editor observed
in the SVAR demo, with Aura's existing data and visual system.

**Architecture:** Configure native SVAR flexible columns and sidebar Editor; compact
BoardViewsBar and update the existing BoardCardContent using Aura Badge. Keep the provider,
data model, free-text tags and global shell intact.

**Tech Stack:** React, TypeScript, SVAR React Kanban 2.6.0, Tailwind, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-01-board-ui-design.md`.

## Global Constraints

- Presentation only; no schema, API, permission, dependency or global shell changes.
- Retain free-text tags, explicit save, delete confirmation, source and conversation/task
  marks, translations, themes, self-hosted fonts and keyboard focus.
- WSL implementation checks; files below 600 lines. Preserve unrelated dirty files.
- Work on master per the operator's established preference. Execution is authorized by
  the operator's "procedi" following the concrete five-change proposal.

## Review Focus

- Mobile: flexible columns scroll within the board; the editor and its buttons fit.
- Long titles, tags and filter values: no document overflow or unreachable controls.
- Collapsed columns: remaining columns fill available space and expand normally.
- Language/theme: readable priority and tag text in Italian/English and light/dark.
- Save/cancel/filter/view interactions: presentation changes preserve stored content.

## Decisions taken while writing this plan

- Retain free-text tag input: stock MultiCombo cannot create a new tag.
- Use native `fixedColumnWidth: false` and `placement="sidebar"`, not custom sizing logic.
- Reuse Badge and token colors. Do not add tests that merely pin CSS classes; measure
  responsive geometry in Playwright and retain behavioral save/filter tests.
- No progress, covers or assignees: Aura's card contract does not persist those fields.
