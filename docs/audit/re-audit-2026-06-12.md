## Falsified reference-comparison claims (discarded)

One agent claimed Aura "runs tools sequentially (comment-only P1)" and "lacks a breaker check." Direct reads falsify both:
- **Concurrent dispatch IS implemented** — `llm_agent_parallel.go executeBatch` runs a batch through a semaphore (default 4, `AURA_LOOP_MAX_PARALLEL_TOOLS`); results re-serialized in call order. No leak (goleak/`-race` green).
- **The breaker IS checked before each call** — `llm_agent_stream_retry.go:25` calls `breaker.Allow()` before every `client.Stream`, feeds `.Success()`/`.Failure()`.

These claims are not in the findings. (The agent's *reference observations* — nanobot checkpoint recovery, stream idle watchdog, state-machine tracer — are valid and corroborate B-01/B-08/O-08.)
