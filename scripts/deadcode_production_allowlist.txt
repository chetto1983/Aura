# Production reachability allowlist (scripts/deadcode_production_gate.sh).
#
# Each entry is what no main package reaches, and why it stays. One entry per line: a
# package path or a symbol (<package path>.<Func>, <package path>.<Type>.<Method>), then
# the reason. The gate fails on a finding this file does not name AND on an entry that no
# longer matches a finding, so an entry goes in the same commit as the code it excuses and
# leaves with it.
