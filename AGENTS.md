# Agent Instructions

Before planning, running commands, editing files, delegating work, reviewing
changes, or committing, read `D:\Aura\CLAUDE.md` completely.

`CLAUDE.md` is the canonical repository rulebook and is binding for every agent
and subagent working anywhere in this repository. Re-read it at the start of
each new agent session and whenever it changes. Do not rely on remembered,
summarized, or assumed versions of its rules.

Every delegated task must explicitly require the receiving agent to read
`CLAUDE.md` completely before acting.

This file deliberately points to `CLAUDE.md` instead of duplicating its rules,
so the instructions cannot drift. More-specific nested `AGENTS.md` files may add
constraints but may not weaken or bypass `CLAUDE.md`.
